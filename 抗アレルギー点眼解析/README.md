# 抗アレルギー点眼解析

抗アレルギー点眼薬9成分（NDBオープンデータ 2014〜2024年度）の解析。
既存の `allergy解析/` とは独立した自己完結プロジェクトで、生Excel（`data/raw/`）のみを共有する。

**主解析は公費レセプトを**含まない**集計に統一**している。第1回〜第10回（2014〜2023年度）は
公費含まない集計のみが公表されており、2024年度だけ「含む」版を使うと時系列に定義の不連続が生じるため。

## なぜ新しく作ったか

旧 `allergy解析/` の成果物と、Desktop に置かれていた3つのMDには次の問題があった。

1. **秘匿レポート2本の数値が全面的に誤り**
   - 総計列の特定に失敗し、薬効分類コード「131」を総処方量として出力していた
   - 秘匿セルを47の都道府県列ではなく、ヘッダの文字列列（薬価基準収載医薬品コード・単位）から
     数えていたため、欠落率が全行で機械的に99〜100%になっていた
   - 入院シートの総計秘匿行を一律「欠落量=0」としていた（実際は全量が不明）
2. **後発品比率の年次系列が成分ごとの事情を無視していた**
   - 2021年度以前は上位品目の足切りで後発品が非掲載になる成分があり、
     公表値から算出したGE比率が実態を表さない
3. **「統一名収載品」を後発品メーカー社数に1社として加算していた**

## 対象9成分

エピナスチン塩酸塩／オロパタジン塩酸塩／レボカバスチン塩酸塩／ケトチフェンフマル酸塩／
クロモグリク酸ナトリウム／トラニラスト／ペミロラストカリウム／イブジラスト／アシタザノラスト水和物

薬効分類131（眼科用剤）かつ品目名に「点眼」を含む行を対象とする。
シクロスポリン（パピロックミニ）・タクロリムス（タリムス）は本解析の対象外。

## 秘匿の扱い

外用薬の処方数量は**1,000未満のセルが「-」で秘匿**される。総計列には秘匿セルの値も含めた
真の合計が入るため、次式で秘匿分の総量が復元できる。

```
欠落量 = 公表された「総計」列の値 − Σ(開示された47都道府県セル)
```

| 分類 | 定義 | 欠落量 |
|---|---|---|
| 秘匿なし | 47都道府県すべて開示 | 0 |
| 部分秘匿 | 一部の県が「-」 | 総計 − Σ開示 |
| ブロック秘匿 | 総計は公表されているのに47都道府県すべてが「-」 | 総計の全額 |
| 総計秘匿 | 総計自体が「-」 | **算出不能**（品目全体が1,000未満なので上限は999） |

## 後発品比率の解釈（最重要）

**GE比率の経年比較は2022年度以降に限定すること。**

NDBオープンデータは第8回（2021年度）まで薬効分類ごとに上位品目しか公開せず、
処方量の小さい後発品銘柄は品目ごと非掲載だった。第9回（2022年度）で足切りが緩和された結果、
眼科用剤の公開品目数は154 → 522に急増している。
**2021→2022のGE比率の急上昇は、大半が公開仕様の変更であって後発品置換の進行ではない。**

成分×年度ごとに次の4分類を付与している（`ge_share_annotated.csv` の `ge_class` 列）。

| 区分 | 定義 | 経年比較 |
|---|---|---|
| A | 真値0%（後発品が未収載） | 使える |
| B | 算出不能（後発品は収載済みだが足切りで非掲載） | **使えない** |
| C | 比較不能（後発品の収載初年度・部分年のみ） | **使えない** |
| D | 信頼可（2022年度以降、足切り撤廃後） | 使える |

代表例（レボカバスチン、後発品は2008年収載済み）:

- 2014年度の**0.0%は「後発品が無い」という意味ではない**。上位30品目の足切りで全社が非掲載
- 2020年度56.0% → 2021年度44.6% の低下は市場実態ではなく、掲載銘柄が3→2に減っただけ

詳細は `03_解析結果/後発品_剤形/ge_share_report.md`。

## 年齢性別軸で分かったこと

都道府県軸と同じ算出方法・同じ秘匿4分類を年齢性別ファイル（性別×21年齢階級、
2014〜2015年度は性別×19年齢階級）にも適用した。同じ品目・同じ年度でも、
**軸によって秘匿パターンがまったく異なる**ことが分かった。

- 2016・2017年度のエピナスチン・オロパタジン・レボカバスチンは、都道府県軸では
  ほぼ全県開示（欠落率1%未満）なのに、年齢性別軸では**全セルがブロック秘匿**
  になっている（旧 `drug_by_drug_summary.md` が主張していた「エピナスチン
  2016/2017年度に年齢性別ファイルで全42セルがブロック秘匿」は実データで裏付けられた）。
- 秘匿発生率は年齢階級ごとに偏りがあり、90歳以上（52〜62%）と0〜4歳（45%）で高く、
  10〜14歳・70〜74歳付近（34〜36%）で低い。処方量が少ない年齢層ほど閾値未満に
  なりやすいという直感と整合する。
- 総計秘匿（総計列自体が「-」）の対象品目・対象年度は都道府県軸と完全に一致する
  （総計列は軸に依存しない、当然の結果）。

詳細は `agesex_censoring_report.md`（統合版⑤章）。

## 未収載品目まで拡張した秘匿感度分析

従来の秘匿感度分析は「NDBに掲載されている品目の中の秘匿セル」だけを対象にしていたが、
2021年度以前は上位品目の足切りにより、PMDA薬価基準には収載されているのにNDBには
行そのものが無い（未収載）品目がある。`build_unlisted_sensitivity.py` はこれを
2つのシナリオ（順位ベース上限・2022年度シェアからの逆推計上限）で定量化した。

**結論**: 2021年度以前は、公表値だけからは真の総量を有意に絞り込めない
（識別区間幅が公表値と同オーダーに達する年度・成分がある。例: クロモグリク酸
2018年度は+1600%超）。**2022年度以降は区間がほぼ消え、公表値をそのまま真値として
扱ってよい水準まで縮む。** 秘匿セルの補完方法（zero/upper等）を精緻化するより、
「未収載品目の存在」のほうが桁違いに大きな不確実性である。

詳細は `05_論文成果物/公費含めない_new/unlisted_sensitivity_report.md`（統合版⑦章）。
逆推計シナリオは「品目の市場シェアが年度をまたいで安定する」という仮定に依存し、
その仮定が崩れると判断した年度・成分（GE収載初年度、ブロック秘匿で実績不明、
市場構造の断絶）は算出していない（空欄）。

## 単位の正規化（最重要・成分をまたぐ集計の前提）

9成分の処方数量は**単位が揃っていない**。正規化せずに合算すると値が量として成立しない。

| 単位 | 成分 | mL換算 |
|---|---|--:|
| ｍＬ | エピナスチン・オロパタジン・レボカバスチン | ×1 |
| 瓶 | ケトチフェン・クロモグリク酸Na・トラニラスト・ペミロラスト・イブジラスト・アシタザノラスト | ×5 |
| 個 | クロモグリク酸Na（インタール点眼液UD、2016〜2018年度） | ×0.35 |

`src/units.py` が品目名末尾の容量表記からmL換算係数を求め、`build_extract.py` が
`ml_factor` / `total_ml` / `value_ml` として抽出データに埋め込む。
成分をまたぐ集計（`ALLERGY_EYE_TOTAL` / `ANTI_HIST` / `MED_RELEASE`）は必ずmL換算後に行うこと。

正規化しないと ALLERGY_EYE_TOTAL は 2022〜2024年度で 11〜13%、2015〜2018年度で
2.6〜9.4% 過小評価される。さらに瓶単位の6成分がNDBに一斉収載された
**2021→2022年度に見かけ上の断絶が生じる**（足切り撤廃の影響と混ざるため要注意）。

同一成分・同一年度の中では単位が揃うため、**先発/後発シェアは換算の有無に依らない**。

## 秘匿セルの上限に999を使わない理由

NDBは補完的秘匿（complementary suppression）を行っており、**「秘匿セルは必ず1,000未満」
という前提は成立しない**。1セルだけ伏せると総計から逆算できるため、閾値を上回るセルでも
巻き添えで伏せられる。実データでも部分秘匿行に「秘匿セルがちょうど1個」の行は
両軸とも0行で、`missing` が 秘匿セル数×999 を超える行が都道府県軸8行・年齢性別軸41行ある。

そのため区間の上限は「各セルは非負」「行内の秘匿セルの合計は `missing` に一致」の
2つの事実だけから `[0, missing]` として導く。詳細と検証結果は
`05_論文成果物/公費含めない_new/pipeline_audit_findings.md`。

## 既知の限界

- **数量は「1日量×日数」の積算**であり、患者数とは分離できない。処方量の増加を患者数の増加と
  解釈してはならない。
- **都道府県は患者の居住地ではなく医療機関・薬局の所在地**である。
- **ブロック秘匿された品目は都道府県別解析から丸ごと欠落する**（総計ベースの集計には影響しない）。
- **総計秘匿の品目はGE比率の分子・分母に算入できない**。すべて小規模な後発品銘柄のため、
  GE比率をわずかに過小評価する方向に働くが、影響は総量の0.01%未満。
- **2024年10月開始の選定療養（選）品目**は年度の約半分しか含まない。先発品として通常行と合算している。
