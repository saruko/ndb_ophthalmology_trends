# NDBオープンデータを用いた日本の眼科診療トレンド解析：結果データ

以下は、NDBオープンデータ（第1回〜第10回：2014年度〜2023年度）を用いた眼科主要手術の全国トレンド・地域格差・関連要因分析の全結果です。この情報をもとに論文原稿（英文ジャーナル投稿用）を作成してください。

---

## 研究デザイン・方法

### データソース
- **主データ**: 厚生労働省 NDBオープンデータ 第1回（2014年度）〜第10回（2023年度）
- **A400補正**: 第3回（2016年度）以降のNDBオープンデータでは、短期滞在手術等基本料3（A400）で算定された白内障手術が手術テーブルから分離されている。本研究では「短期滞在手術等基本料_都道府県別算定回数」ファイル（第3回〜第10回）から白内障手術（K282）の短手3データを都道府県別に抽出し、手術テーブルの件数に加算することでデータの一貫性を確保した。
- **共変量データ**:
  - 人口・65歳以上人口: 総務省統計局「人口推計」（2015年は国勢調査実数、2020年は補間補正人口実数、他年は人口推計）
  - 眼科医師数: 厚生労働省「医師・歯科医師・薬剤師統計」（偶数年調査、奇数年は線形補間）
  - 眼科標榜施設数: 厚生労働省「医療施設調査 静態調査」（2014/2017/2020/2023年実施、中間年は線形補間）

### 解析対象
| コード | 診療行為名 | 説明 |
|--------|-----------|------|
| J039-2 | 抗VEGF薬注射 | 注射薬の主要眼科用抗VEGF薬（アイリーア、ルセンティス、バビースモ等）薬剤数量を代替指標として合算 |
| K282 | 水晶体再建術（白内障手術） | 眼内レンズを挿入する場合（その他のもの）= K282_ro。2016-2023年はA400短手3データを加算して補正済み |
| K280 | 硝子体茎顕微鏡下離断術（硝子体手術） | K280_1（網膜付着組織を含むもの）＋ K280_2（その他のもの）の合算 |
| K268 | 緑内障手術 | 全8電算処理コードの合算。2022年のコード体系変更（MIGS関連新コード追加）によりAPC分析は2014-2021年に限定 |
| K259 | 角膜移植術 | 角膜移植術（150086210）のみ |

- **除外**: K281（増殖性硝子体網膜症手術）は秘匿閾値により解析対象外
- **秘匿値の補完**: 10件未満で秘匿されたセルは0で補完（zero imputation）

### K282のA400補正について
NDBオープンデータの手術テーブルにおけるK282の計上方法は年度により異なる:
- **2014-2015年**: 短手3コード（190179210等）が手術ファイル内に含まれており、追加補正不要
- **2016-2017年**: 短手3が手術ファイルから完全に除外され、A400テーブルに移動。約44万件/年が脱落していた
- **2018-2023年**: 短手3の大部分が手術ファイルの通常コード（150253010）に再統合されたが、約10万件/年がA400に残存

本研究では全年度（2016-2023年）のA400ファイルからK282短手3データを抽出し加算することで、一貫した時系列データを構築した。

### 統計手法
1. **APC（Annual Percent Change）**: 対数線形回帰 log(rate) = β₀ + β₁×year, APC = (exp(β₁)−1)×100
2. **Joinpoint回帰**: pwlf（Piecewise Linear Fitting）による2セグメント折れ線対数回帰
3. **地域格差指標**: Gini係数、変動係数（CV）、最大/最小比
4. **Spearman順位相関**: 都道府県別施行率 vs 高齢化率・眼科医密度・施設密度
5. **パネル回帰**: Two-way固定効果（都道府県FE＋年FE）、都道府県クラスター頑健標準誤差
6. **感度分析**: 共変量が実測値の調査実施年のみ（2014, 2016, 2018, 2020, 2022年）でパネル回帰を再推定

### K268のAPC分析期間の制限について
K268（緑内障手術）は2022年度のNDB改定でMIGS関連の新術式コード（流出路再建術 眼内法、水晶体再建術併用眼内ドレーン挿入術等）が追加され、2021→2022年で全国件数が35,728→86,207件（+141%）と急増した。この不連続性はコード体系変更によるアーティファクトであり、連続性を仮定するAPC・Joinpoint回帰を適用することは統計学的に不適切であるため、K268のAPC・Joinpoint分析は**コード体系が一貫している2014-2021年に限定**した。2022-2023年のデータはトレンド表に参考値として記載するが、回帰分析の対象からは除外した。

## 考察のポイント

### 1. 抗VEGF薬注射の爆発的普及
- 10年間で件数が約3倍（318,358→959,061件）、APC=+12.25%
- Joinpointで2017年を境にAPC減速（24.97%→8.43%）：初期の急速な普及フェーズから安定成長フェーズへ移行
- 地域格差（Gini: 0.254→0.108）の著明な縮小 → 地方への均てん化が進行

### 2. 白内障手術の安定成長（A400補正後）
- A400補正により2016-2017年の不自然な件数低下が解消され、一貫した増加トレンドが確認（APC=+3.19%, p<0.001）
- 最も地域格差が小さい手術（Gini=0.062）
- Joinpointで2021年を境にAPC加速（2.34%→8.08%）：COVID-19からの回復後の急増を反映

### 3. 硝子体手術の着実な増加
- APC=+3.35%で安定的に増加、2020年はCOVID-19の影響で一時減少
- 感度分析で眼科医密度が有意 → 専門医の供給が施行率を規定する可能性

### 4. 緑内障手術（2014-2021年のトレンド）
- コード体系変更前の実質APC=+7.51%（R²=0.93）、特に2016年以降はAPC=+10.08%と加速
- MIGS（minimally invasive glaucoma surgery）の普及を反映
- 2022年以降の急増（+141%）はコード体系変更アーティファクトであり、回帰分析から除外
- 地域格差が大きい（Gini=0.206, 最大/最小比=5.7倍）

### 5. 角膜移植術の特異性
- 件数はほぼ横ばい（APC=−0.57%, n.s.）
- **唯一地域格差が拡大**（Gini: 0.405→0.465）
- パネル回帰で施設密度のみ有意（p=0.032） → 特定高度医療施設への集中

### 6. パネル回帰の解釈
- Two-way FEでは共変量のほとんどが非有意 → 施行率の都道府県間差は構造的固定要因に起因
- これは「共変量が無関係」ではなく「年FEが共通トレンドを吸収する」ため

## Limitations

1. NDBオープンデータは10件未満を秘匿するため、小規模都道府県や希少術式では0補完によるバイアスが生じうる
2. J039-2（抗VEGF薬注射）は薬剤数量の代替指標であり、実際の注射回数とは厳密には一致しない
3. K282（白内障手術）はA400（短手3）データによる補正を行ったが、2014-2015年と2016年以降ではA400の報告形式が異なるため、完全な一貫性は保証されない
4. K268（緑内障手術）は2022年のコード体系変更により2014-2021年と2022-2023年の連続性が断絶している。APC分析は2021年で打ち切った
5. 共変量（眼科医数・施設数）は調査実施年以外は線形補間値
6. NDBは保険診療のみを対象とし、自由診療（多焦点IOLの選定療養等）は含まれない
7. A400の両側手術コード（190195910）は1件=両眼手術であり、片側コードと算定単位が異なる可能性がある
