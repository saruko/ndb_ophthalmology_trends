# 翼状片手術（K224）の年度別・地域別トレンド解析

NDBオープンデータ（第1回〜第11回：2014〜2024年度）を用いて、翼状片手術の地域偏在
（南方好発として知られる分布の偏り）が年度ごとにどう推移するかを解析するサブプロジェクト。

---

## 1. 背景と目的

翼状片は紫外線曝露との関連が示唆され、沖縄・鹿児島など南方地域での好発が知られている。
本解析では、都道府県別の手術件数（人口10万対）の偏在度合いを年次で定量化し、
その偏りが2014〜2024年の間に維持されているか・縮小しているかを明らかにする。

実データでも偏在は明瞭である（例：2024年外来 沖縄1,196件 vs 青森177件）。

### 2.3 秘匿（10件未満マスク）の状況 ※抽出前に実データで確認済み

| シート | 秘匿状況 |
|---|---|
| 外来（2015〜2024） | 全年度・全都道府県で秘匿なし（完全データ） |

> **【重要】2017年入院の全県非公表について**
> 第4回NDBオープンデータ（2017年度）の入院シートは、K224を含む一部術式で
> 全国合計（4,549件）のみ公表・都道府県別は全県「-」となっている。
> 厚労省公式ページから再ダウンロードしたファイル（000711860.xlsx）とも完全一致しており、
> 差し替え前の版やダウンロード時の破損ではなく、**公表データ自体の仕様**である。
> 二次秘匿（逆算防止のための連鎖的秘匿）が全県に及んだものと推定される。
> 前年2016年は秘匿0県、翌2018年は秘匿2県であり、実際に全県10件未満であったとは考えられない。

## 3. 解析デザイン

### 3.1 抽出パターン（3系統）

| パターン | 対象シート | 対象年度 | 2017年の扱い |
|---|---|---|---|
| ① 外来のみ（**主解析**） | 外来 | 2015〜2024 | 通常どおり使用（秘匿なし） |
| ② 入院のみ | 入院 | 2015〜2024 | **欠測として除外**（実質9年分：2015-2016, 2018-2024） |
| ③ 外来+入院 | 全体(2014) / 外来+入院(2015〜) | 2014〜2024 | **欠測として除外**、またはプロット時は破線・注記付き |

- ①を主解析とする理由: 翼状片手術の約8割は外来であり、かつ外来は全期間で秘匿ゼロの完全データであるため。
- ②③で2017年を除外する理由: 入院分（合算の約17%）を0補完すると2017年だけ人工的な谷・
  地域分布の歪みが生じ、ジニ係数が無意味な値になるため。

### 3.2 指標

1. **人口10万対手術件数**: 各都道府県・各年度について `件数 / population_total × 100,000`
2. **地域偏在の年次推移**:
   - ジニ係数（年次推移）
   - 変動係数 CV（年次推移）
   - 計算方式（人口重み付けの有無）は本体パイプライン `../src/analysis.py` と同一方式に
     統一し、他の眼科術式（白内障・緑内障等）との比較可能性を担保する。

### 3.3 秘匿値の補完と感度分析

- ①外来: 秘匿ゼロのため補完不要。
- ②入院・③合算: 2018年以降の少数秘匿県（毎年2県前後）について、本体パイプラインと同じ
  `zero` / `five` 補完の両方で実行し、ジニ係数・CVの結論が補完方法に依存しないことを確認する
  （入院は件数が小さく、補完値の相対的影響が大きいため必須）。

## 4. 注釈事項（限界・次回以降の検討項目）

1. **2014年（第1回NDB）の位置づけ**: 第1回は公表仕様が他年度と異なる（外来/入院の区分なし等）
   ため、③のトレンド解析では2014年を「参考値」として脚注扱いとする。
2. **年齢構造の未調整**: 本解析は粗率（crude rate）である。翼状片手術は高齢者に多く、
   都道府県間の年齢構成の差（例：沖縄 vs 秋田）が偏在指標に混入しうる。
   年齢調整（`population_65plus` を利用可能）は次回以降の検討項目とする。
3. **紫外線曝露の代理変数**: 緯度・日照時間との相関解析（南方偏在の直接検証）は
   次回以降の検討項目とする。
4. **NDBオープンデータの一般的限界**: レセプト件数ベースであり患者実数ではないこと、
   受療地ベース（患者住所地ではなく医療機関所在地）の集計であること。

## 5. パイプライン構成（実装方針）

`allergy解析/` と同様の独立パイプライン構成とし、本体 `../src/` は変更しない。
コード抽出・都道府県ヘッダー検出・秘匿値補完のロジックは本体 `../src/preprocess.py` の
方式を踏襲する（電算コード 150080210 でマッチング）。

## 6. 紫外線・日射量データ収集（追加解析用）

紫外線曝露と翼状片偏在の相関分析に向けて、2種類のアプローチでデータを収集・整備しました。

1. **気象庁（JMA）日最大UVインデックス解析値**:
   - `fetch_jma_uv.py` にて全国56地点（代表47都道府県庁所在地）の年間推移グラフ（PNG画像、計517枚）を気象庁からダウンロードし、画像解析（Pillow + NumPyによる棒グラフ検出）で数値データ（月別平均）を復元しました（計6,204件）。
   - 結果: [jma_uv_index_monthly.xlsx](file:///F:/マイドライブ/NDB_眼科診療トレンド解析_研究計画書/翼状片解析/紫外線/jma_uv_index_monthly.xlsx) / [jma_uv_index_annual_mean.csv](file:///F:/マイドライブ/NDB_眼科診療トレンド解析_研究計画書/翼状片解析/紫外線/jma_uv_index_annual_mean.csv)
2. **Open-Meteo 日積算全天日射量**:
   - `fetch_openmeteo_radiation.py` にて47都道府県庁所在地の緯度・経度から、2014〜2024年（約18.8万日分）の日積算全天日射量を取得し、集計しました。
   - 結果: [openmeteo_radiation_monthly.xlsx](file:///F:/マイドライブ/NDB_眼科診療トレンド解析_研究計画書/翼状片解析/紫外線/openmeteo_radiation_monthly.xlsx) / [openmeteo_radiation_annual_mean.csv](file:///F:/マイドライブ/NDB_眼科診療トレンド解析_研究計画書/翼状片解析/紫外線/openmeteo_radiation_annual_mean.csv)

両データともに、沖縄県が北海道に対して強度が明らかに高い南北勾配（UVインデックスで1.46〜1.66倍、日射量で1.25〜1.30倍）が正確に再現されていることを確認済みです。
