# NDB 翼状片手術（K224）トレンド・地域格差・紫外線相関解析

**Regional disparity and UV correlation of pterygium surgery using NDB Open Data (2014–2024)**

NDBオープンデータ（第1回〜第11回：2014年度〜2024年度）の**手術（shujutsu）**ファイルから
**K224 翼状片手術（弁の移植を要するもの）**を抽出し、全国トレンド・都道府県別の地域偏在・
紫外線曝露との関連を定量化するパイプライン。

翼状片は紫外線曝露との関連が示唆され、沖縄・鹿児島など南方地域での好発が知られている。
本解析では偏在の度合いを年次で定量化し、2014〜2024年の間に維持されているか・縮小しているかを
明らかにする。

### 2-3. 抽出パターン（3系統）

| パターン | 対象シート | 対象年度 | 2017年度の扱い |
|---|---|---|---|
| ① 外来のみ（**主解析**） | 外来 | 2015〜2024 | 通常どおり使用（秘匿なし） |
| ② 入院のみ | 入院 | 2015〜2024 | **欠測として除外**（実質9年分） |
| ③ 外来+入院 | 全体(2014) / 外来+入院(2015〜) | 2014〜2024 | **欠測として除外**（プロット時は破線・注記付き） |

①を主解析とする理由: 翼状片手術の約8割は外来であり、かつ外来は全期間で秘匿ゼロの完全データであるため。
②③で2017年度を除外する理由: 入院分（合算の約17%）を0補完すると2017年度だけ人工的な谷・
地域分布の歪みが生じ、ジニ係数が無意味な値になるため。

## 4. 解析手法

- **人口10万対**: `件数 / population_total × 100,000`
- **APC**: 対数線形回帰 `log(rate) ~ year` の傾きから `(exp(β)-1)×100`。2017年度は②③で除外
- **地域格差**: ジニ係数・変動係数（CV）・最大最小比。計算方式は本体パイプライン
  [`../src/analysis.py`](../src/analysis.py) と同一に統一し、他の眼科術式（白内障・緑内障等）との
  比較可能性を担保している
- **紫外線相関**: 解析A（県内時系列, N=9-11年, BH法でFDR補正）と解析B（年度別の47県横断）の2本立て

### 出力値の丸め規則
プロジェクト全体の統一規則に従う（[../README.md](../README.md) セクション4.3を参照）。

| 対象 | 桁数 |
|---|---|
| 人口10万対手術件数 | 小数2桁 |
| ジニ係数・変動係数CV・最大/最小比 | 小数3桁 |
| APC（%） | 小数2桁 |
| R² | 小数4桁 |
| p値 | 小数3桁、0.001未満は `<0.001`（`fmt_p()`） |

本解析の率は 3.7〜91（人口10万対）と小さいため、共通規則の「整数」ではなく小数2桁とする
（整数にすると入院の 3.67 が 4 になり有効数字が1桁に落ちる）。
共通規則の趣旨は「有効数字3桁以上を保つ」であり、これに従っている。

2種類のアプローチでデータを収集している。

| ソース | 取得スクリプト | 出力 |
|---|---|---|
| 気象庁 日最大UVインデックス解析値 | `fetch_jma_uv.py` | `jma_uv_index_monthly.xlsx` / `jma_uv_index_annual_mean.csv` |
| Open-Meteo 日積算全天日射量 | `fetch_openmeteo_radiation.py` | `openmeteo_radiation_monthly.xlsx` / `openmeteo_radiation_annual_mean.csv` |

- 気象庁データは全国56地点（代表47都道府県庁所在地）の年間推移グラフPNG（計517枚、`jma_images/`）を

- Open-Meteoは47都道府県庁所在地の緯度・経度から2014〜2024年（約18.8万日分）を取得。
- 両データとも沖縄県が北海道に対して明らかに高い南北勾配（UVインデックスで1.46〜1.66倍、
  日射量で1.25〜1.30倍）を再現していることを確認済み。

## 6. データ上の重要な制限事項

### 6-1. 2017年度入院の全県非公表
第4回NDBオープンデータ（2017年度）の入院シートは、K224を含む一部術式で
全国合計（4,549件）のみ公表・都道府県別は全県「-」となっている。
厚労省公式ページから再ダウンロードしたファイル（000711860.xlsx）とも完全一致しており、
差し替え前の版やダウンロード時の破損ではなく、**公表データ自体の仕様**である。
二次秘匿（逆算防止のための連鎖的秘匿）が全県に及んだものと推定される。
前年2016年度は秘匿0県、翌2018年度は秘匿2県であり、実際に全県10件未満であったとは考えられない。

### 6-2. 秘匿（10件未満マスク）の分布
| シート | 秘匿状況 |
|---|---|
| 外来（2015〜2024） | 全年度・全都道府県で秘匿なし（完全データ） |
| 入院（2015〜2024） | 2018年度以降は毎年2県前後が秘匿。**2017年度は47都道府県すべて非公表** |

①外来は秘匿ゼロのため補完不要。②③については `zero` / `five` 補完の両方で実行し、
ジニ係数・CVの結論が補完方法に依存しないことを確認している（入院は件数が小さく、
補完値の相対的影響が大きいため必須）。

### 6-3. 入院の最大最小比は定義できない年度がある
zero補完では件数0の県が生じる。2024年度入院では徳島県が0件のため最大最小比が `nan` になる
（ジニ係数・CVは算出可能）。入院の地域格差は最大最小比ではなくジニ/CVで評価すること。

### 6-4. 2014年度（第1回NDB）の位置づけ
第1回は公表仕様が他年度と異なる（外来/入院の区分なし）ため、③のトレンド解析では
2014年度を「参考値」として脚注扱いとする。

### 6-5. 年齢構造の未調整
本解析は粗率（crude rate）である。翼状片手術は高齢者に多く、都道府県間の年齢構成の差
（例：沖縄 vs 秋田）が偏在指標に混入しうる。年齢調整（`population_65plus` を利用可能）は
次回以降の検討項目とする。

### 6-6. 紫外線相関は生態学的関連にとどまる
都道府県単位の集計値どうしの相関であり、個人レベルの曝露–発症関係を示すものではない
（生態学的誤謬）。また解析A（県内時系列）はN=9-11年の小標本で検出力が低く、
UV・手術率の双方に経年トレンドがあると見かけの相関が生じうる（時系列の擬似相関）。

### 6-7. ⚠️ 2024年度のみ公費レセプトを含む（時系列の不連続）

**本解析の2024年度の値は、2023年度以前と集計定義が異なる。**

第11回（2024年度）から公費レセプトを**含む**集計が標準になった一方、第1回〜第10回
（2014〜2023年度）は**含まない**集計のみが公表されている。本解析が使う
`data/raw/ndb_shujutsu_2024.xlsx` は標準ファイル＝**公費含む**である。

同じ第11回で両版が手元にある唯一の診療行為（G016 硝子体内注射）で実測した差:

| G016算定回数 | 2023年度 | 2024年度 |
|---|---:|---:|
| 標準ファイル（公費含む） | 1,039,173 | 1,104,430 |
| 公費含まない版 | 1,039,173 | 1,067,660 |
| 差 | **0** | **+36,770（+3.44%）** |

K224でも同程度の上振れが2024年度のみに生じていると考えられる。

**具体的な影響**
- 2024年度の全国手術件数（29,233件）・人口10万対（23.61）は約3%過大の可能性
- 外来APC +1.04%/年（p=0.021）は、2024年度の上振れ分だけ上方バイアスを受ける。
  この程度のバイアスは有意性判定を変えうるため、**APCの解釈には注意が必要**
- 地域格差指標（Gini 0.267 等）は比率なので影響は小さいが、公費比率に県間差があれば残る

**対応方針（2026-08-02 決定）: 当面はこのまま運用し、論文の Limitations に明記する。**
処方薬については `data/raw/ndb_2024_nokouhi/` に含まない版があるが、
**手術（shujutsu）の含まない版は未入手**である。取得できれば `--nokouhi` 相当の切り替えを
追加して再実行する。

Limitations にそのまま使える記載文（日本語・英語）は
[../README.md](../README.md) §6-3 にある。

### 6-8. NDBオープンデータの一般的限界
レセプト件数ベースであり患者実数ではないこと、受療地ベース（患者住所地ではなく
医療機関所在地）の集計であること。

## 7. 主要な結果（zero補完・2024年度）

- **全国手術件数 29,233件**（人口10万対23.61）。内訳は外来24,690件（19.94）・入院4,543件（3.67）
- **APCは外来 +1.04%/年（95%CI +0.20〜+1.89、p=0.021）で有意な微増**。
  入院 −0.71%/年（p=0.335）、合算 +0.62%/年（p=0.066）は有意でない
- 地域格差（外来）: Gini 0.267、CV 0.556、**最大/最小比 11.2倍
  （最大 沖縄県 81.58件 / 最小 東京都 7.26件）**。南方好発の分布が明瞭に再現されている
- **紫外線との横断相関は強く安定**: JMA UVインデックス × 外来手術率は
  全年度でPearson r=+0.70〜+0.78（全年度平均 r=+0.745、Spearman ρ=+0.678）。
  合算でも平均 r=+0.704。入院では弱い（全年度平均 r=+0.317）
- Open-Meteo日射量との相関は JMA UVインデックスより弱い。県内時系列相関（解析A）は
  FDR補正後に有意となる県がほとんどなく、参考解析にとどまる
