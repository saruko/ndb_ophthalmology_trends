## 主要結果（03_解析結果/summary_report.txt）

**切り口1 術式別時系列**
- 総手術 88,019 (2014) → 186,713 (2024)、2.12 倍。非レーザー 3.26 倍、レーザー 1.43 倍。
- 観血手術に占める線維柱帯切除術のシェア 44.1% (2014) → 14.0% (2024)。件数も 2022 年 17,997 → 2024 年 15,170（−15.7%）と初めて減少に転じた。
- プレートなしインプラント（K268-4）が 2022 年 3,291 → 2024 年 15,688 件（4.8 倍）。ExPRESS は 2019–22 年に 3.0–3.8 千件で安定していたため増分は PRESERFLO と解釈できる。
- 眼内法流出路再建術（2022 年〜分離）33,422 → 41,842、iStent/Hydrus+PEA 25,669 件 (2024)。隅角手術が非レーザーの 66.7%。
- SLT（K273）10,644 → 44,788（4.2 倍）、2023→2024 で +26%。LI は 43,518 → 28,960（−33%）。

**切り口2 COVID-19**
- 2020 年の総手術は 2014–19 トレンド外挿値の 0.99（ほぼ影響なし）。濾過手術のみ 2020 年に −14.9% の水準低下（p=0.002）で 2021 年に回復。
- 2021 年以降は総数・レーザーがトレンド上方に乖離（2024 年 O/E 1.20）。角膜シャント・毛様体光凝固は 2022 年以降プラトー（傾き変化 p<0.01）。

**切り口3 都道府県格差**
- 非レーザー手術率の都道府県 CV 0.48 (2014) → 0.39 (2024)、Gini 0.25 → 0.19、いずれも有意に縮小（p<0.01）。総手術・隅角手術・隅角レーザーも縮小し、**識別区間の上限でも同符号・有意**（`robust_to_censoring=True`）。
- チューブシャント・毛様体凝固の格差縮小は**上限では有意でない**（希少術式で秘匿セルが多いため）→ 論文では断定を避ける記述に。
- 線維柱帯切除術・濾過手術は縮小せず（CV 0.61→0.65）、LI は拡大（CV 0.68→0.93, p<0.001）。
- 県順位は安定（非レーザー 2014 vs 2024 の順位相関 ρ=0.72）。2024 年上位: 島根・宮崎・岡山・広島・大分、下位: 福島・秋田・岐阜・岩手・青森。
- 二方向固定効果パネル回帰では眼科医密度・施設密度・高齢化率は総手術率と関連せず（Tanito Table 3 と整合）。SLT のみ眼科医密度と正の関連（p=0.015）。

**切り口4 年齢**
- 年齢標準化率（2015 年人口基準）: 非レーザー 26.3 → 79.4、レーザー 43.5 → 57.4 /10 万。
- 非レーザーは 60 歳以上で 3 倍以上に増加（MIGS+白内障同時手術）；iStent は 65 歳以上が 87%、平均 74.3 歳。
- レーザーは 50 歳未満で 2–6 倍（SLT の早期適用）；SLT の 65 歳以上割合 76.8% → 70.9%。
- レーザーの男女比 0.39 → 0.61 に上昇（LI＝女性優位 から SLT＝男女同等 へのシフト）。

## データ上の制約（論文に記載すべき事項）

1. 2014・2015 年の K273（隅角光凝固）都道府県別は原データで全セル秘匿 → 都道府県別 laser/total は 2016 年から。
2. 2016 年の K268-2 入院・性年齢別が全セル秘匿（総計 9,910 件のみ）→ 2015/2017 年分布で按分補完（`imputed=1`）。
3. 10 未満セルは主解析で 0（下限）＝**先行研究 Tanito 2023 と同一処理**（FY2020 の県別率レンジが論文 Figure 2 の凡例と一致することで確認）。
   上限は行ごとに `missing = 公表総計 − Σ開示セル` を復元し `min(9, missing)`。**セル一律 9 は補完的秘匿のため上限として無効**
   （都道府県軸 174/179 行、性年齢軸 114/115 行で違反）。→ `build_censoring_bounds_surgery.py` が毎回検証。
4. K268-4「プレートなし」は ExPRESS と PRESERFLO を区別できない。K268-6 は iStent と Hydrus を区別できない。
5. 同時施行手術は 1 術式のみ算定（Tanito と同じ）。needling（K268-7, 2022〜）は Tanito 互換集計から除外。
6. 2015 年以降は外来+入院の合算。2014 年は「全体」シートのみ。
