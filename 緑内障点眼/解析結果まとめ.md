## 1. 背景と目的

緑内障は日本人の中途失明原因の第1位であり、治療の中心は眼圧下降点眼薬である。
点眼薬は薬効群が多岐にわたり、近年は配合点眼薬・Rhoキナーゼ阻害薬・EP2受容体作動薬など
新しい選択肢が加わった。一方で全国規模の処方実態、とくに薬効群間の相対的な位置づけ、
年齢・性別分布、地域差を悉皆データで記述した報告は乏しい。

本研究はNDBオープンデータを用い、(1) 緑内障点眼薬の薬効群別処方量と構成、
(2) 年齢・性別分布、(3) 都道府県間の地域差、(4) 収載品目を固定した長期トレンド、
(5) 後発品置換の進行、を記述することを目的とする。

## 2. 方法

### 2.1 データ源

厚生労働省NDBオープンデータ第1〜11回（2014〜2024年度）の「外用薬」都道府県別集計および
年齢性別集計を用いた。都道府県別集計は外来（院内処方）・外来（院外処方）・入院の3シートから成り、
本解析では3シートを合算した。

主解析は**公費レセプトを含まないデータ**とした。第1〜10回（2014〜2023年度）は公費レセプトを
含まない集計のみが公表されており、第11回（2024年度）のみ「含む／含まない」の両方が公表されている。
2024年度だけ「含む」版を用いると時系列に定義の不連続が生じるため、第11回は
「処方薬 公費レセプトを含まないデータ」に差し替えた。

人口分母は総務省人口推計、眼科医師数は医師・歯科医師・薬剤師統計、眼科標榜施設数は
医療施設調査に基づく都道府県別共変量（`data/covariates/prefecture_covariates.csv`）を用いた。

### 2.2 対象薬剤

薬効分類 **131（眼科用剤）** かつ医薬品名に「**点眼**」を含む品目のうち、
眼圧下降を適応とする成分を対象とした。眼軟膏および原末は「点眼」を含まないため除外される。

11年度通算で **149品目**（先発品48、後発品101）が該当した（Suppl Table 2）。

アプラクロニジン（アイオピジンUD点眼液）はレーザー治療後等の一過性眼圧上昇に対する
短期使用薬であり、慢性緑内障治療の処方量とは性質が異なるため**別掲とし全体合計に含めない**。

2024年10月開始の長期収載品の選定療養により、同一銘柄が「通常分」と「（選）」の2行に
分割収載されている。品目単位で数量を追う際は両者を合算した（合算しないと2024年度だけ
見かけ上減少する）。

### 2.3 薬効群の分類

日本緑内障学会「**緑内障診療ガイドライン（第5版）**」の眼圧下降点眼薬の分類に準拠し、
互いに排他な10群に分類した（合計＝緑内障点眼薬全体）。

| 薬効群 | 含まれる成分 |
|---|---|
| プロスタグランジン関連薬 | ラタノプロスト、トラボプロスト、タフルプロスト、ビマトプロスト（FP受容体作動薬）／オミデネパグイソプロピル（EP2受容体作動薬）／イソプロピルウノプロストン（イオンチャネル開口薬） |
| 交感神経β遮断薬 | チモロール、カルテオロール、レボブノロール（非選択性）／ベタキソロール（β1選択性） |
| 交感神経α1β遮断薬 | ニプラジロール |
| 交感神経α1遮断薬 | ブナゾシン |
| 交感神経α2刺激薬 | ブリモニジン |
| 交感神経非選択性刺激薬 | ジピベフリン |
| 副交感神経刺激薬 | ピロカルピン（直接型）／ジスチグミン（間接型） |
| 炭酸脱水酵素阻害薬 | ドルゾラミド、ブリンゾラミド |
| Rhoキナーゼ阻害薬 | リパスジル |
| 配合点眼薬 | ザラカム・デュオトラバ・タプコム・ミケルナ（PGA＋β）／コソプト・アゾルガ（CAI＋β）／アイベータ（α2＋β）／アイラミド（α2＋CAI）／グラアルファ（ROCK＋α2） |

配合点眼薬は複数の薬効群にまたがるため、単剤の薬効群とは重複させず独立群として扱った。
これにより10群は排他となり、シェアと全体合計が整合する。

補助的に、配合剤を成分に分解した**成分ベース曝露量**（PG関連薬／β遮断薬／炭酸脱水酵素阻害薬／
α2刺激薬／Rhoキナーゼ阻害薬）も算出した。これらは群間で重複するため、シェア・合計の計算には用いず
別系列として扱う。

### 2.4 処方数量のmL統一換算

NDBオープンデータの処方数量は品目ごとに単位（`ｍＬ`／`瓶`／`個`）が異なる。
本解析では**すべてmLに統一換算**した。

容器単位（瓶・個）で収載されている品目はすべて品名末尾に容量が明記されており、mL単位の品目は
品名に容量を含まない。この対応規則を「単位」列（第3回＝2016年度分以降にのみ存在）と全行照合した結果、
**1,595行で不一致0件**であった（年齢性別ファイルを含む照合では3,138行で不一致0件）。
単位列のない2014・2015年度も同一品名で整合するため、全11年度で換算できる。

換算対象は次の9品目のみで、残り140品目はすべて`ｍＬ`単位である。

| 品目 | 公表単位 | 換算 |
|---|---|---:|
| サンピロ点眼液0.5% / 1% / 2% / 3% / 4%（各5mL） | 瓶 | ×5.0 mL |
| コソプトミニ配合点眼液 0.4mL | 個 | ×0.4 mL |
| タプロスミニ点眼液0.0015% 0.3mL | 個 | ×0.3 mL |
| エイベリスミニ点眼液0.002% 0.3mL | 個 | ×0.3 mL |
| アイオピジンUD点眼液1% 0.1mL（別掲） | 個 | ×0.1 mL |

### 2.5 秘匿セルの扱い

外用薬の秘匿閾値は処方数量1,000未満であり、該当セルは「-」で公表される。
真値は区間 [0, 1000) にあるため、主解析では識別区間の下限である**0で補完**した。
感度分析として上限（999）補完でも全指標を計算し、公表値のみから到達可能な
**識別区間**を提示した（Suppl Table 5、結果 §3.7）。

都道府県セル総数78,114のうち24,751セル（31.7%）が秘匿されているが、秘匿されるのは少量セルであるため
数量ベースで失われる割合は年度により0.01〜4.4%にとどまる（Suppl Table 3A）。
ただし成分によっては影響が大きく、ジスチグミンは数量の93%が失われるため都道府県別解析には用いない
（Suppl Table 3B）。

### 2.6 解析期間の設定 ―― 収載品目の不連続への対処

**NDBオープンデータは第10回（2022年度分）から外用薬の収録品目が大幅に増えた。**
2021年度以前は各薬効分類の上位品目（実質的に先発品と一部の後発品）しか収載されていない。
収載品目数は2021年度の30品目から2022年度の137品目へ増加した（Suppl Table 1・3C。別掲のアプラクロニジンを含む数）。
その結果、全体合計は2021年度172.7百万mLから2022年度224.5百万mLへ約30%増えているが、
これは処方実態の変化ではない。

そこで解析を2系統に分けた。

1. **主解析（薬剤間・薬効群間の比較）: 2022〜2024年度に限定**
   全品目が収載されたフルカバレッジ期間であり、薬剤間の量比較・シェア・地域差を
   収載バイアスなく比較できる。Table 1・2・3・4、Fig 1・2・3・6 はこの期間に基づく。

2. **長期解析（トレンド）: 収載品目を固定した均衡パネル**
   - **Panel A**: 2014〜2024年度の11年度すべてに連続収載された**6品目**
     （キサラタン点眼液0.005%、タプロス点眼液0.0015%、アイファガン点眼液0.1%、
     エイゾプト懸濁性点眼液1%、トルソプト点眼液1%、コソプト配合点眼液。いずれも先発品）
   - **Panel B**: 2015〜2024年度の10年度すべてに連続収載された**20品目**
     （Panel Aの6品目に加え、ザラカム・タプコム・アゾルガ・コソプトミニ・タプロスミニ・
     グラナテック・ミケランLA2%・チモプトール0.5%・デタントール・トラバタンズ・ルミガン・
     レスキュラ・ラタノプロスト「ニットー」「TOA」）

   収載品目が固定されているため収載拡大の影響を受けない。ただし対象は個々の「品目」であり、
   後発品を含む成分全体の量ではない。Table 5・Fig 4 がこれに当たる。

### 2.7 統計解析

- **年平均変化率（APC）**: 人口10万対処方数量の対数を年に回帰し、APC＝(exp(β₁)−1)×100。
  95%信頼区間は β₁±1.96×SE を指数変換して算出
- **地域差**: 都道府県間の変動係数（CV）、ジニ係数、最大／最小比、Theil T index
- **共変量との関連**: 高齢化率・眼科医師数（人口10万対）・眼科施設数（人口10万対）との
  Spearman順位相関、および都道府県・年度の二元固定効果パネル回帰
  （都道府県クラスター頑健標準誤差）
- **市場構造**: 全体合計に対するシェア、都道府県×年度のHerfindahl-Hirschman Index
- **治療的代替**: シェアの1階差分を二元固定効果パネル回帰し、負の係数を代替の証拠とみなす
- **収束**: σ収束（CVの年次回帰）、β収束（初期値と成長率の回帰）
- **年齢調整**: 間接標準化。全国の年齢層別処方率を都道府県の年齢構成に当てはめて期待値を求め、
  標準化処方比 SPR＝観測値／期待値、年齢調整率＝SPR×全国粗率とした。
  年齢層は**0–64歳と65歳以上の2層**である。NDBオープンデータは都道府県別の年齢内訳を
  公表しておらず、都道府県×年齢人口として利用できるのが人口推計の年齢3区分に由来する
  総人口と65歳以上人口のみであるため。直接法は都道府県別の年齢層別処方率を必要とするため
  本データでは実施できない
- **秘匿の感度分析**: 0補完（下限）と999補完（上限）で全指標を再計算し、識別区間の幅、
  シェア順位の入れ替わり、都道府県ランキングのSpearman相関を評価した

有意水準は両側5%とした。解析は Python 3.13（pandas 2.3.3、statsmodels 0.14.5、
linearmodels、pwlf）で実施した。

### 2.8 数値の丸め

先行研究（抗アレルギー点眼薬解析）と同一の規則を適用した。処方数量・人口・人口10万対は整数、
シェア（%）は小数1桁、比率（0–1）・比・CV・ジニ・回帰係数・標準誤差・t値は小数3桁、
APC（%）は小数2桁、R²は小数4桁。p値は生値を保持したうえで表示用文字列（3桁、0.001未満は`<0.001`）
を併記した。すべての解析結果CSVには実測値列の直後に丸め列（`_rounded`）を付してある。

## 3. 結果

### 3.1 対象品目と後発品

<!-- ここに Fig 5 を配置 -->

11年度通算で149品目（先発品48、後発品101）が対象となった。2024年度に収載されていたのは136品目（別掲のアプラクロニジンを含めると137品目）である。

後発品の判定はNDBオープンデータに識別列がないため品名から行った
（先発品名で始まる＝先発品、メーカー名「」を含む＝後発品（銘柄別収載）、
それ以外の一般名表記＝後発品（統一名収載））。

**後発品の数量シェア**は2022年度27.9%、2023年度29.6%、2024年度**34.8%**と上昇した（Fig 5A）。

### 3.3 単剤の減少は配合剤への移行である

<!-- ここに Fig 6 を配置 -->

#### 年齢調整後の地域差

処方量の77%が65歳以上に集中するため、粗率は都道府県の年齢構成をそのまま反映する。

- **副交感神経刺激薬は区間幅104%**であり、絶対値を論じることはできない。
- 都道府県ランキングの頑健性は群によって大きく異なる。全体（ρ=0.907）・ROCK（0.999）・
  配合剤（0.995）・CAI（0.988）・α2刺激薬（0.975）は頑健だが、
  β遮断薬（0.757）・α1β遮断薬（0.828）は中程度、**副交感神経刺激薬（ρ=0.033）は
  ランキング自体が意味を持たない**。

## 4. 考察

**配合点眼薬が最大の薬効群となった。** 2024年度の処方量の32.1%を占め、
プロスタグランジン関連薬単剤（30.5%）を上回った。3年間でシェアを2.3ポイント伸ばしており、
その伸びは単剤PG関連薬と単剤β遮断薬のシェア減少と有意に対応している。
配合剤の利点（点眼回数の削減によるアドヒアランス向上、防腐剤曝露の低減）を考えると
臨床的に合理的な変化であるが、**配合剤には後発品が存在しない**ため、
配合剤シフトは薬剤費の観点では後発品置換の効果を相殺する方向に働く。
この二面性は医療経済的な検討に値する。

**単剤の減少を処方の縮小と読んではならない。** 交感神経α2刺激薬とRhoキナーゼ阻害薬は
単剤では大きく減少したが、成分ベースでは逆に増加していた。配合剤を含む薬効群の解析では、
単剤の集計と成分ベースの集計を併記する必要がある。

**地域差は小さく、緑内障治療の標準化が進んでいることを示唆する。** 全体量の最大／最小比1.53倍は、
先行研究の抗アレルギー点眼薬より小さい。ただし使用頻度の低い薬効群では地域差が10倍を超えており、
「専門性が高い（＝稀にしか使われない）薬剤ほど地域差が大きい」という構造
（ρ=0.935）は他の眼科領域と共通する。

**粗率の順位は年齢構成に強く歪められている。** 年齢調整（間接標準化）を行っても格差の
大きさはほとんど変わらない（CV 0.098→0.094）一方で、順位は最大26位動いた。
粗率で最下位だった沖縄県は32位へ、粗率9位の秋田県は35位へ移動する。
すなわち**「沖縄県で緑内障点眼薬の処方が少ない」という粗率の所見は、
主として同県の高齢者割合が低いことの反映であり、治療機会の不足を示すものではない**。
逆に年齢調整後に最も高いのは愛知県（SPR 1.181）、次いで宮城県・石川県・東京都であった。
都道府県比較を行う際は粗率ではなく年齢調整値を用いるべきである。

年齢調整後にもなおSPRが0.80〜1.18の幅を持つことは、年齢構成以外の要因
（受療行動、眼科医療資源の分布、健診受診率、診断閾値）が地域差を生んでいることを示唆する。

**年齢分布は緑内障の疫学と整合する。** 処方量の77.4%が65歳以上に集中し、85–89歳でピークとなる。
90歳以降の減少は疾患頻度の低下ではなく、通院・点眼手技・治療目標の変更を反映していると考えられ、
超高齢者の緑内障治療継続という臨床課題を示唆する。

## 5. 限界

1. **収載品目カバレッジの不連続**。2021年度以前と2022年度以降の処方量は直接比較できない。
   本研究は薬剤間比較を2022〜2024年度に限定し、長期トレンドは均衡パネルで評価することで
   対処したが、2021年度以前の薬効群別の水準は過小評価である。
2. **均衡パネルは品目の追跡であり成分の追跡ではない**。Panel A/Bの減少は当該品目が
   後発品等に置換されたことを示すもので、成分全体の使用量の減少ではない。
3. **秘匿による過小評価**。少量成分ほど影響が大きく、ジスチグミンは都道府県別で93%が失われる。
   主解析は0補完（識別区間の下限）であり、真値はこれ以上である。感度分析（Suppl Table 5）により
   全体量の識別区間幅は+4.3%、主要4群は4%未満と確認したが、β遮断薬（+17.1%）・
   α1β遮断薬（+24.8%）・副交感神経刺激薬（+104.1%）は区間が広い。とくに
   **β遮断薬と炭酸脱水酵素阻害薬のシェア順位（4位／5位）は補完戦略により入れ替わる**ため、
   両群の順位は断定していない。
4. **年齢調整は2層（0–64歳／65歳以上）に限られる**。NDBオープンデータは都道府県別の
   年齢内訳を公表しておらず、本リポジトリが保持する都道府県×年齢人口も人口推計の
   年齢3区分に由来する総人口と65歳以上人口のみであるため、間接標準化を2層で行った。
   処方量の77%が65歳以上に集中することから主要な交絡は除去できていると考えられるが、
   65歳以上の内部（65–74歳と85歳以上では処方率が2倍以上異なる）の構成差は調整されていない。
   都道府県×5歳階級人口を追加取得すればより細かい調整が可能である。
   また直接法は都道府県別の年齢層別処方率を必要とするため本データでは実施できない。
5. **処方数量は「量」であり患者数ではない**。NDBオープンデータには患者数の集計がないため、
   有病率・治療率としては解釈できない。点眼回数、両眼／片眼の別、実際の使用量も不明である。
6. **適応症が特定できない**。ピロカルピン・ジスチグミンは調節性内斜視等にも用いられ、
   ビマトプロスト・タフルプロストは睫毛貧毛症治療薬との区別ができない
   （ただし睫毛貧毛症治療薬グラッシュビスタは薬効分類が異なるため本解析には含まれない）。
7. **配合剤の成分分解は数量ベース**である。1本あたりの成分量ではなく点眼液量で按分しているため、
   成分ベース曝露量は「その成分を含む点眼液の量」であって成分の絶対量ではない。
8. **公費レセプトを含まないデータ**を用いているため、公費負担医療（指定難病等）で処方された分は
   含まれない。緑内障は多くが公費対象外であるため影響は限定的と考えられるが、定量はできない。
8. 都道府県共変量の眼科医師数・施設数は調査年が隔年であり、年次補間を含む。
