# Kabata et al. (2026) の図表を再現するCSV

Kabata Y, Terauchi R, Nakano T. *Nationwide trends and regional variation in intravitreal injections
and anti-VEGF agent use in Japan from 2017 to 2022: An analysis of the NDB Open Data.*
PLoS One. 2026;21(5):e0348087.

同論文のFigure・Tableを作図・作表するためのCSVを、本フォルダのデータ
（**全年度「公費レセプトを含まない」**）で生成したもの。
先行研究はFY2017–2022を対象とするが、本CSVは取得済みの全期間
（薬剤 2014–2024年度、G016 2015–2024年度）を収録している。

生成: `python 抗VEFG薬/build_kabata_tables.py` の後 `python 抗VEFG薬/organize_outputs.py --nokouhi`
（本フォルダ `05_先行研究再現_Kabata/` に振り分けられる）
（`--kouhi` を付けると公費レセプトを含むデータ版を親フォルダに生成）

## 先行研究からの拡張点

1. **観察期間を延長**（FY2022 → FY2024）
2. **ラニビズマブの先発とバイオシミラーを分離**。先行研究の "ranibizumab" は両者の合算である
   （例: FY2021の161,937は先発157,164＋BS 4,773）
3. **アフリベルセプト8mg（FY2024収載）とペガプタニブを追加**
4. 全年度で公費レセプトの取り扱いを統一（`README.md` 参照）

## 未生成の図表と理由

以下は本フォルダのデータでは作成できない。追加のデータ取得が必要。

| 論文の図表 | 必要なデータ | 状況 |
|---|---|---|
| **Fig 2**（月次推移 FY2019–2022） | NDBオープンデータ「医科診療行為 G注射 **診療月別**算定回数」 | **未取得**。年度ごとに厚労省サイトからのダウンロードが必要 |
| **S2 Table の75歳以上分母** | 都道府県×**75歳以上**人口 | **未取得**。`data/covariates/prefecture_covariates.csv` は年齢3区分（0–14/15–64/65+）のみ。暫定として65歳以上分母の列を併記している |
| **S3 Table**（間接年齢調整、<75/≥75） | 同上 | **未生成**。上記の75歳以上人口が前提 |
| **S4 Table の年齢調整列** | 同上 | 粗利用率と65歳以上分母の2指標のみ生成 |

### 代替として実施したこと

- S2・S4では75歳以上分母の代わりに**65歳以上分母**の列を出力している（列名 `rate_65plus_*` / `per_100k_65plus`）。
  先行研究の値とは定義が異なるため、直接の比較はできない。
- 論文本文のPoisson GEEによる年次率比・地域指標の推定は本CSVには含まれない
  （必要であれば `kabata_prefecture_rates_by_year.csv` から算出可能）。

## 注意

- FY2014はG016のデータが存在しない（第1回NDBオープンデータに医科診療行為「G注射」の区分がないため）。
  `kabata_table1_national_counts.csv` の該当セルは空欄。薬剤の数量のみ収録している。
- 薬剤の数量はバイアル・シリンジ本数であり、G016は算定回数である。
  両者の比は97.9〜99.7%で推移しており（`03_解析結果/G016硝子体内注射/g016_vs_drug_validation.csv`）、
  先行研究が示した「G016は抗VEGF注射活動の妥当な代理指標」という主張と整合する。
