# 秘匿バイアス解析

NDBオープンデータの秘匿セル（算定回数10未満の「-」マスク）が、格差指標や
トレンド推定にどれだけバイアスを与えるかを検証するサブ解析。

本体パイプライン（`../src/preprocess.py`）のローダーを共用し、手術・処置データを対象とする。

---

## 1. 実行方法

```bash
python 秘匿バイアス解析/run_censoring_pipeline.py
```

`scripts/` の s01〜s09 を順に実行する。出力は `processed/`（`plots/` を含む）。

| ステップ | 内容 |
|---|---|
| s01 | 秘匿フラグ付き抽出 |
| s02 | 秘匿率センサス（全数調査） |
| s03 | bounds analysis（識別区間） |
| s04 | 人工秘匿実験（単一代入3法） |
| s05 | 区間打ち切りMLE（実データ適用） |
| s06 | 打ち切りMLEの実験評価 |
| s07 | 図の生成 |
| s08 | sharp bounds |
| s09 | ベイズ多重代入 |

結果は [RESULTS.md](RESULTS.md)、設計は [research_plan.md](research_plan.md)、
原稿ドラフトは [manuscript_draft.md](manuscript_draft.md) を参照。

> 本フォルダは他のサブ解析と違い、番号付きフォルダ構成（`01_抽出データ` 等）には
> 統一していない。従来どおり `processed/` 直下に出力する。

## 2. ⚠️ 2024年度のみ公費レセプトを含む（時系列の不連続）

**本解析の2024年度の値は、2023年度以前と集計定義が異なる。**

第11回（2024年度）から公費レセプトを**含む**集計が標準になった一方、第1回〜第10回
（2014〜2023年度）は**含まない**集計のみが公表されている。
本解析は本体と同じ `data/raw/ndb_shujutsu_*.xlsx` / `ndb_shochi_*.xlsx` を読むため、
2024年度だけ公費レセプトを含む。

同じ第11回で両版が手元にある唯一の診療行為（G016 硝子体内注射）で実測した差:

| G016算定回数 | 2023年度 | 2024年度 |
|---|---:|---:|
| 標準ファイル（公費含む） | 1,039,173 | 1,104,430 |
| 公費含まない版 | 1,039,173 | 1,067,660 |
| 差 | **0** | **+36,770（+3.44%）** |

**具体的な影響**
- 2024年度の算定回数が約3%上振れするため、**同年の秘匿率はわずかに低く出る**
  （閾値10未満に該当するセルが減る方向）。s02の秘匿率センサスは2024年度だけ
  他年度と比較可能性が落ちる
- APCの識別区間（s08 `sharp_bounds_apc.csv`）は、区間の上下端がともに
  2024年度の上振れ分だけ押し上げられる
- 秘匿の**構造**（小規模県に集中する等）に関する結論は、公費の有無で変わらないため影響は小さい

**対応方針（2026-08-02 決定）: 当面はこのまま運用し、論文の Limitations に明記する。**
`data/raw/ndb_2024_nokouhi/` にあるのは処方薬とG016のみで、
**手術・処置の「含まない」版は未入手**である。取得できれば本体ごと切り替えて再実行する。

Limitations にそのまま使える記載文（日本語・英語）は
[../README.md](../README.md) §6-3 にある。混在の全体像は同 §6-1／§6-2 を参照。
