# 初回実行結果サマリー（2026-07-12）

## s01/s02: 秘匿の実態（全数調査）

- 抽出セル 15,463 のうち **5,266（34.1%）が秘匿**（"-" 表記、区間 [1,9]）。
- コード別秘匿率の上位: K282_ring_y 99.3%、K282_ring_n 95.0%、K282_capsule 83.4%、
  K281-2 82.1%、K280-2 74.0%。既存解析で除外された **K281 は 38.5%**。
- 主解析対象の K282_ro（4.7%）・K280_1（2.0%）は秘匿の影響がほぼ無い一方、
  緑内障サブグループ（K268_iridectomy 61.7% 等）は補完法の影響を強く受ける。
- 都道府県別では人口小規模県で秘匿率が高い（青森 51.7%、高知・福井 48.6%、山梨 47.7%、秋田 47.1%、鳥取 46.2%）。
  → 秘匿は地理的にランダムでなく小規模県に集中するため、**地域格差指標に系統的バイアス**を生む。

## s03: 部分識別（bounds analysis）

秘匿セルに 1 / 9 を代入した際の指標の識別区間（`bounds_disparity.csv`, `bounds_apc.csv`）:

- **APCの符号は多くのコードで識別可能**（例: K281 は [+19.9%, +34.6%] で「増加」は頑健）だが、
  **大きさは識別不能**（幅14.7ポイント）。K268_istent は [+65.0%, +108.3%]（幅43.3）。
- Gini の識別区間幅はコード平均で最大 0.48（K282_ring_n）。秘匿率 <5% のコードでは幅 ≈0。
- 含意: 秘匿率の高いコードについて点推定値（0補完等）のみを報告する既存慣行は、
  データが識別できない精度を主張していることになる。

## s04: 人工秘匿実験（K282, binomial thinning, 200反復）

真値既知の下での補完法別バイアス（`artificial_censoring_summary.csv`）:

| 秘匿率 | 0補完 Giniバイアス | 5補完 | 乱数補完 | 0補完 APCバイアス(pt) |
|---|---|---|---|---|
| 12.7% | **+0.040** | +0.010 | +0.011 | +0.38 |
| 46.0% | **+0.190** | +0.005 | +0.028 | +1.63 |
| 75.3% | **+0.353** | −0.174 | −0.056 | +3.48 |
| 77.0% | **+0.409** | −0.277 | −0.092 | +6.34 |

- **0補完（本プロジェクトのデフォルト）は Gini を一貫して過大推定**し、
  秘匿率 12.7% でも +0.04 と無視できない。APC も正方向に歪む。
- 5補完は中程度の秘匿率では最良だが、高秘匿率では逆方向に大きく歪む。
- どの単一代入も高秘匿率では破綻 → 打ち切り尤度推定（Step 5）の動機付けが実データで示された。

## s05: 区間打ち切りMLE（2026-07-12 継続実行）

**前提の検証で重要な発見**: "-" は常に「10件未満秘匿（区間[1,9]）」ではない。
K281 の2016・2017年入院層は前後年に各県1000件超があるのに**全47都道府県が "-"**
（項目レベルの非公表）。これを [1,9] として扱うと大きなバイアスを生むため、
「全県秘匿の年×層」「層数が最頻値と異なる年」を除外するルールを
`scripts/structural.py` に共通化し、s03/s05 に適用した。

- この除外により K281 の APC bounds は [+19.9%, +34.6%] → **[−2.20%, −2.17%]** に一変。
  当初の「急増」は構造的欠測（2014年の1層構成・2016/17年の入院層全県非公表）による
  純粋なアーティファクトだったことが判明。**構造的欠測の見落としは秘匿補完よりも
  桁違いに大きいバイアス源**である（論文の中核的知見の一つ）。
- 打ち切りNB-MLE（都道府県×層固定効果＋対数線形トレンド、秘匿セル尤度 P(1≤Y≤9)）:
  K281 APC = −1.34% (95%CI −1.75, −0.92)、K281-2 = −13.1%、K268_iridectomy = −5.0%、
  K268_device_plate = +13.5%、K259 = −1.8%、K280-2 = −28.3%（`censored_mle_apc.csv`）。
  秘匿率24〜80%のコードを「除外せずに」推定可能になった。
- Poissonは過分散により多くのコードで非収束、NBは全コードで収束（K281-2除く）。

## 最終化（2026-07-12 完了）

- βのSEを完全な観測情報行列（数値ヘッセ行列の逆行列、固定効果との共分散込み）から
  算出するよう修正。CIは正直に広がった（例: K281 NB 95%CI −2.23〜−0.43）。
- 人工秘匿実験にNB版MLEを追加（`experiment_mle_summary.csv`）。等分散DGPの下で
  NB≈Poisson（高秘匿率帯でRMSE差<0.01）であり、枠組みの優位は分布仮定に頑健。
- 秘匿率×人口の相関を検証: Spearman ρ = −0.855（p < 10⁻¹³, 対2020年総人口）。
- 2022年度（第9回）を境に複数コードで秘匿率が急減する公表仕様のレジーム変化を発見
  （K280-2 98%→13% 等）。単一代入バイアスの時間非定常性→擬似joinpointの機序として原稿に記載。
- 図表: `processed/plots/fig1_censoring_heatmap.png`（秘匿率ヒートマップ）、
  `fig2_gini_bounds.png`（Gini識別区間、6年度以上残るコードに限定）、

## 拡張の実装（2026-07-12 追記: 「今後の課題」を解消）

- **s08 シャープ識別区間**: APCは厳密解（β = Σ c_t log S_t の単調性から年別に最適代入）、
  Giniは座標降下探索。端点代入区間は識別幅を最大2桁過小評価しており（K281-2: 幅0.31 vs
  35.7ポイント）、K281-2・K280-2・K268虹彩切除・K259 の4コードでは**増減の符号すら
  識別されない**（端点代入では符号が頑健に見えていた）。論文の中核的知見に昇格。
- **s09 多重代入**: MLE漸近分布からのパラメータ抽出×切断NBサンプリング（M=500）で
  Gini係数の95%区間を算出。モデル仮定下の不確実性（幅0.003〜0.033）が識別区間
  （幅0.02〜0.44）より桁違いに狭いこと＝「精度の大部分はモデル仮定由来」を定量化。
- 残る限界は「Gini識別区間の大域最適性の保証」と「完全ベイズ（MCMC）化」のみで、
  いずれも結論の方向を変えない性質のもの（原稿の限界1・4に明記）。
