# 処方数量の単位に関する検証（allergy解析 全体）

**結論から言うと、現状の `allergy解析` パイプラインは単位を統一していない。**
NDBオープンデータの「総計（処方数量）」列の値を、単位（`ｍＬ` / `瓶` / `個`）にかかわらず素のまま合算し、原稿ではそれを一律「mL」と表記している。

検証日: 2026-07-27 ／ 検証対象: NDBオープンデータ第1〜11回 外用薬、薬効分類131かつ「点眼」を含む品目のうち、`src/preprocess_allergy.py` の `DRUG_CATEGORIES` が拾う11成分。

---

## 1. NDBオープンデータの「単位」列

外用薬シートには「医薬品名」の隣に**「単位」列**があり、処方数量がどの単位で集計されているかが品目ごとに示されている。**この列は2016年度（第3回）以降にのみ存在し、2014・2015年度（第1・2回）には存在しない**（2014・2015年度の単位判定については第1.1節を参照）。全11年度・全シートを走査した結果、対象11成分の単位は以下のとおりであった。

| 単位 | 成分 | 2024年度の品目数 |
|---|---|---:|
| **ｍＬ** | エピナスチン、オロパタジン、レボカバスチン | 44 |
| **瓶**（＝5 mL） | ケトチフェン、トラニラスト、クロモグリク酸、ペミロラスト、イブジラスト、アシタザノラスト、**タクロリムス** | 43 |
| **個**（＝0.4 mL） | **シクロスポリン**（パピロックミニ点眼液0.1% 0.4mL） | 1 |
| **個**（＝0.35 mL） | クロモグリク酸のうちインタール点眼液UD 2% 7mg0.35mL（過年度のみ収録） | — |

「瓶」の品目はすべて品名に `５ｍＬ` を含む5 mL製剤である（例: `ザジテン点眼液０．０５％　３．４５ｍｇ５ｍＬ`、`リザベン点眼液０．５％　２５ｍｇ５ｍＬ`、`タリムス点眼液０．１％　５ｍＬ`）。

つまり **主要3成分（エピナスチン・オロパタジン・レボカバスチン）だけが真に mL 単位**であり、それ以外の8成分は容器数（瓶・個）で集計されている。

## 1.2 `ALLERGY_EYE_TOTAL` の単位混在は年度により 0〜14.6% と変動する

一方 `ALLERGY_EYE_TOTAL`・`ANTI_HIST`・`MED_RELEASE`・`IMMUNO` は、非mL成分が収録された年度で影響を受ける。年度ごとの収録成分数と、素の合算値・mL換算値の差は以下のとおりである（各年度の公表「総計」列、2024年度は公費レセプトを含まない版）。

|---|---:|---|---:|---:|---:|

| 2015 | 7 | アシタザノラスト, クロモグリク酸, シクロスポリン, トラニラスト | 129,856,400 | 142,397,800 | +9.66% |
| 2016 | 6 | クロモグリク酸, シクロスポリン, トラニラスト | 133,336,000 | 137,873,000 | +3.40% |

| 2018 | 5 | アシタザノラスト, クロモグリク酸 | 167,661,400 | 172,147,600 | +2.68% |
| 2019 | 3 | （なし） | 150,777,400 | 150,777,400 | **0.00%** |

**歪みの大きさが年度により 0%〜14.6% と変動する点が重要である。**したがって `ALLERGY_EYE_TOTAL` を年度間で比較すると、単位混在に由来する見かけの変動が加わる。ただし原稿は経年比較にすべて `TOP3_TOTAL` を用い、`ALLERGY_EYE_TOTAL` は2024年度の単年断面（Table 1、Fig 1A/1B、Table 2）にのみ使用しているため、この年度間変動が結果に混入することはない。原稿が「全薬剤合計は収録品目数が年度により変動するため、単年断面の記述にのみ使用した」としている判断が、結果的に単位混在の問題にも有効に働いている。

## 2. 現状のコードの挙動

`src/preprocess_allergy.py` の `load_gaiyo_sheet()` は「単位」列を読まず、都道府県セルの数値をそのまま `count` に格納する。

```python
for col_idx, pref_name in pref_col_map.items():
    raw_val = df.iloc[r_idx, col_idx]
    count = clean_count_value(raw_val, imputation_strategy)
    records.append({... "count": count})
```

`build_national_totals.py`、`build_allergy_age_sex.py` も同様に「総計」列・内訳セルを素のまま合算する。集計カテゴリ（`ANTI_HIST` / `MED_RELEASE` / `IMMUNO` / `ALLERGY_EYE_TOTAL`）は、この単位混在の値を単純加算して作られている。

原稿（`allergy_paper_draft_kouhihukumanai.md`）はこの値を一貫して「mL」と記載している（例:「2024年度の全国処方数量は208,090,121 mL」）。

## 5. 免疫抑制点眼薬サブ解析での扱い

`シクロスポリンとタクロリムス/` のサブ解析では、2成分の単位が「個」（0.4 mL）と「瓶」（5 mL）で異なり、そのまま足すと意味を持たないため、単位を明示して分離した。

- 各剤単独の指標 … **素の数量（個・瓶）と mL換算値の両方**を出力（`count_published` / `count_ml`、`count_per_100k` / `count_ml_per_100k`）
- 2剤合計（`IMMUNO_ML`） … **mL換算値のみ**

親解析の免疫抑制点眼薬合計 769,983 は「個」と「瓶」の単純和であり、mL換算値 1,080,865 mL とは異なる。両者を対照する際は注意を要する。

なお mL に揃えても、パピロックミニ（1回使い切り0.4 mL容器）とタリムス（5 mL瓶）では1容器あたりの使用期間が大きく異なるため、mL換算値どうしの比較も投与実態の比較としては限界がある。

## 6. 推奨される対応

原稿の主結論に修正は不要だが、以下のいずれかを推奨する。

1. **最小限の対応（推奨）** — Methods に単位の混在を明記する。「NDBオープンデータの処方数量は品目により mL・瓶（5 mL）・個（0.4 mL）で集計されており、主要3成分はすべて mL 単位である。全薬剤合計（Table 1、Figure 1）は単位を換算せずに合算した値であり、mL に統一すると 12.7% 大きくなる」旨を追記し、Table 1 の単位表記を「mL」から「処方数量（NDB公表単位）」に改める。Limitations に「0–19歳／20歳以上比 1.490 は mL換算では 1.382 となる」を追加する。
2. **完全な対応** — `DRUG_CATEGORIES` に品目単位ごとの `ml_per_unit` を持たせ、`preprocess_allergy.py` / `build_national_totals.py` / `build_allergy_age_sex.py` の3か所で mL換算列を追加する。`ALLERGY_EYE_TOTAL` 等の集計カテゴリを mL換算値で作り直す。主要3成分ベースの図表は値が変わらないため、影響は Fig 1A/1B/1C・Table 1・Table 2 の再生成に限られる。

いずれの場合も、`ALLERGY_EYE_TOTAL` と主要3成分ベースの指標を混同しないことが重要である。

## 検証の再現

本文書の数値は、以下の走査により得た（`allergy解析/src/preprocess_allergy.py` の `classify_drug` を再利用）。

1. 各年度のExcel全シートについて、ヘッダー行から「単位」列と「総計（処方数量）」列の位置を動的に検出する
2. 薬効分類131かつ品名に「点眼」を含み、`classify_drug` が成分を返す行を抽出する
3. 「単位」列の値ごとに `ｍＬ`=1.0、`瓶`=5.0、`個`=0.4 を乗じて mL換算値を得る
4. 素の合算値と mL換算値をクラス別・年齢群別に比較する

2024年度は `data/raw/ndb_2024_nokouhi/ndb_gaiyo_2024_nokouhi.xlsx`（公費レセプトを含まない版）を用いた。
