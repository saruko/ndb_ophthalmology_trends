# 05_論文成果物

抗アレルギー点眼薬論文の確定成果物（Fig/Table用CSV・xlsx・原稿docx・pptx）の置き場。

> **このフォルダは自動処理の対象外である。**
> `organize_outputs.py` は本フォルダを走査しないため、パイプラインを何度実行しても
> ここのファイルが動いたり上書きされたりすることはない。
> `generate_paper_csvs.py` などの生成系スクリプトも、直接ここへは書かず
> `processed_nokouhi/論文用CSV/`（ステージング）に出力する。
> 差分を確認したうえで手動でコピーする運用とする。

---

## 1. 2系統の使い分け

| フォルダ | 内容 | 位置づけ |
|---|---|---|
| `公費含まない/` | 全年度を「公費レセプトを含まない」集計で統一 | **主解析。経年トレンドの評価にはこちらを使う** |
| `公費含む/` | 2024年度のみ「公費レセプトを含む」集計 | 参考。時系列に定義の不連続がある |

第1回〜第10回（2014〜2023年度）は公費レセプトを含まない集計のみが公表されている。
2024年度だけ「含む」版を使うと定義が不連続になるため、主解析は `公費含まない/` である。
経緯とデータ差分の詳細は [公費含まない/README.md](公費含まない/README.md) を参照。

2024年度の差は総処方量で **−2.84%**（214,173,368 → 208,090,121）。
2014〜2023年度は全ファイル・全指標で完全一致であることを検証済み。

ファイル名の `_k` サフィックス（`Fig1_age_sex_profile_k.xlsx` 等）は公費含まない版を指す。
CSVは両フォルダで同名・同列構成なので、そのまま差し替えて比較できる。

## 3. 「9剤版」は別系統

`公費含まない/` には、対象薬剤を9剤に絞った別系統のファイルが混在している。
主系統とは集計対象が違うので取り違えないこと。

- `allergy_paper_draft_9agents.md`
- `table1_drug_summary_2024_9agents.csv`
- `age_sex_rates_allergy_9agents.csv`
- `mf_ratio_by_age_allergy_9agents.csv`
- `SupplTable_annual_totals_by_drug_class_9agents.csv` / `.xlsx`

`_9agents` が付かないファイルが主系統である。

## 4. ⚠️ 既知の不整合: `公費含まない/fig3_prefecture_ranking.csv`

**このファイルだけ、公費レセプトを含むデータの値が入っている。**

旧 `generate_paper_csvs.py` はこのファイルを `内容まとめ/`（公費含む世代のスナップショット、
現在は `旧版/内容まとめ/`）からコピーしていたため、公費含まない版として実行しても
2024年度の値が差し替わらなかった。

| ファイル | 2024年_人口10万対 の47県合計 | 判定 |
|---|---|---|
| `公費含まない/prefecture_per_capita_ranking_allergy.csv` | 7,152,633 | 正しい（公費含まない） |
| `公費含まない/fig3_prefecture_ranking.csv` | 7,330,717 | **誤り（公費含む、+2.5%）** |

本来この2ファイルは同一内容であるべきものである。

現在の `generate_paper_csvs.py` は一次出力先から読むよう修正済みで、再実行すれば正しい値が出る。
**Fig 3 を論文に使う場合は差し替えが必要。** 凍結ファイルは自動では上書きしていないので、
`processed_nokouhi/論文用CSV/fig3_prefecture_ranking.csv` を確認のうえ手動で差し替えること。

`fig3_prefecture_ranking_top3.csv` と `fig3_prefecture_by_drug.csv` は再現値と一致しており
（最大絶対差 2.9e-11）、影響を受けていない。
