# 秘匿閾値と識別区間の解説

論文Methodsの「最小集計単位の秘匿」および「秘匿セルの感度分析」の記述が何を意味しているかを、
専門知識を前提とせずに説明する。査読対応や共著者への説明の下敷きとして使うことを想定している。

対象: `allergy_paper_draft_sato_style.md` / `公費含まない/allergy_paper_draft_kouhihukumanai.md`

---

## 1. NDBオープンデータは数字を「隠す」ことがある

NDBオープンデータは日本のほぼ全レセプトの集計表である。ただし
**数字が小さすぎるマスは、そのまま公表すると個人が特定されかねない**ため、
数値の代わりに「−」（ハイフン）が入っている。これが「秘匿」である。

外用薬（点眼薬）の場合、隠す基準は **処方数量1,000 mL未満**。
患者数ではなく「量」が基準である点に注意する。

実際の表はこういう形をしている。

| 薬剤 | 総計 | 北海道 | 青森県 | 岩手県 | … |
|---|---:|---:|---:|---:|---|
| A点眼液 | 500,000 | 45,000 | 12,000 | **−** | … |

岩手県のマスが「−」なのは、実際の数量が1,000未満だったからである。
**本当の値は0以上1,000未満のどこか**だが、それ以上は分からない。

---

## 2. なぜ解析上の問題になるのか

見えているマスだけを足し算すると、**隠れた分だけ実際より少なくなる**。

しかも厄介なのは、**薬剤によって影響の大きさがまったく違う**ことである。

| 薬剤クラス | 秘匿の影響（識別区間の幅、2024年度） |
|---|---:|
| エピナスチン（処方量が多い） | **+0.6%** |
| オロパタジン | +0.9% |
| レボカバスチン | +3.2% |
| メディエーター遊離抑制薬（処方量が少ない） | **+40.2%** |
| 免疫抑制薬（同上） | +15.9% |

エピナスチンのように大量に使われる薬は、隠れるマスがあってもごく一部なので誤差は0.6%程度。
一方、あまり使われない薬は**各県の量が1,000未満になりやすく大量に隠れる**ため、
最大4割も過小評価しうる。

→ **論文で「メディエーター遊離抑制薬・免疫抑制薬の絶対量は幅をもって解釈せよ」と
注意書きしているのは、この理由による。**

---

## 3. 「識別区間」という考え方

隠れた値は分からないが、**範囲は確定している**（0以上1,000未満）。
そこで2通りの極端な計算をする。

- **すべての「−」を 0 とみなす** → 考えうる最小値（本研究の主解析）
- **すべての「−」を 999 とみなす** → 考えうる最大値

この2つの間が「公表データだけから言える確実な範囲」である。

> 例: 2024年度の抗アレルギー点眼薬全体（公費含まない・内訳ベース）
> **207,159,940 〜 212,038,100 mL**

これは推測ではなく**論理的に確定した幅**である。
「真の値は必ずこの中にある」と言い切れるため、
査読で「秘匿の影響を無視している」と批判されにくくなる。

なお地域格差指標（最大/最小比、Gini係数、CV）は補完値に対して単調に動くとは限らないが、
実際に計算すると999充当のほうが格差が小さくなる方向に動いた
（主要3成分合計で最大/最小比 3.143倍→3.027倍）。
したがって**ゼロ補完下の格差推定値は「格差が最も大きく見える側」の評価**にあたる。

## 4. Methodsのあの一文が果たしている役割

> 処方数量1,000未満のセルは「−」で秘匿されている。
> この閾値は全年度・全シートに共通であることを生データで確認した

これは**「隠す基準が本当に1,000なのか、自分で確かめた」という証明**である。
厚労省の資料の記載を鵜呑みにせず検証した、という宣言になる。

検証は逆算による。
**もし基準が本当に1,000なら、公表されている値に1〜999は絶対に登場しないはず**である。
実際に11年分・全シートを走査した結果:

- **1〜999の値は1件も存在しなかった** → 基準は1,000で正しい
- **正の値の最小は毎年きっちり1,000だった** → 基準はちょうど1,000（1,500でも500でもない）

この2点が揃うことで、「識別区間は [0, 1,000) である」という前提が実データで裏づけられる。

### 注意: 「全品目」で見る必要がある

閾値の検証は**薬効分類131の点眼液の全品目**で行う必要がある。
解析対象の11成分だけに絞ると、たまたま1,000ちょうどの値が出現しない年度がある。

| 年度 | 対象11成分に限った最小値 |
|---|---:|
| 2017 | 1,020 |
| 2018 | 1,001 |
| 2019 | 1,020 |
| 2021 | 1,016 |
| 2023 | 1,007 |

これは閾値が年度で違うことを意味しない。単に該当する値が存在しなかっただけである。
**再現を試みる際は対象を「131の点眼液全品目」にすること。**

## 5. 「0」と「−」はまったく違う（今回の修正点）

修正前の原稿には次の記述があった。

> ~~1,000未満の実測値は都道府県別・年齢性別の全シートを通じて1件も存在しない~~

ところが**2022年度（第9回）から、NDBは「0」を明示的に載せるようになった**。
2021年度以前は0のマス自体が存在しなかった。

| 年度 | 0のマス数（公費含む / 公費含まない） |
|---|---|
| 2014–2021 | 0 / 0 |
| 2022 | 22,163 / 22,163 |
| 2023 | 21,220 / 21,220 |
| 2024 | 22,844 / 22,845 |

0は「1,000未満」に含まれてしまうため、**字義どおりに読むと事実に反する**。
そこで「1〜999の値は存在しない」と書き換えた。
**主張したかった中身（閾値は1,000）は正しいので、結論・数値は一切変わらない。**

0と「−」は意味がまったく異なる。

| 表示 | 意味 | 感度分析での扱い |
|---|---|---|
| **0** | 本当に処方が1件もなかった（**公表された実測値**） | 0のまま（999にしない） |
| **−** | 1〜999のどこか（**隠された値**） | 0（下限）または999（上限） |

## 6. 実装上の落とし穴（確認済み）

0と「−」を混同すると、**感度分析で0のマスにまで999を代入してしまい、上限が過大に膨らむ**。

`src/preprocess_allergy.py` の `clean_count_value()` の挙動を確認した結果、正しく区別できていた。

| 入力 | zero補完（主解析） | upper補完（999、感度分析） |
|---|---|---|
| `−` | 0 | **999** |
| `0`（公表値） | 0 | **0** ← 999にしない |
| `1000` | 1000 | 1000 |

主解析（zero補完）では両者とも0になるため数値に差は出ないが、
感度分析の上限値は影響を受ける。
ここが正しく処理されていたので、**論文中の識別区間の数値はそのまま使える。**

## 7. 全国集計に「総計」列を使う理由（関連事項）

秘匿の影響を避けるもう一つの手段が、NDBが各品目行に併記している
**秘匿されない「総計（処方数量）」列**を使うことである。

内訳（都道府県別・年齢性別）を合計する方法では秘匿分が欠落するが、
総計列にはその欠落がない。

| 集計方法 | 2024年度の抗アレルギー点眼薬全体（公費含まない） |
|---|---:|
| 公表「総計」列 | **208,090,121 mL** |
| 内訳セルの合計（ゼロ補完） | 207,159,940 mL |
| 差（＝秘匿による欠落） | 930,181 mL（0.447%） |

このため論文では、
- **全国の処方数量・薬剤別シェア・経年トレンド → 総計列**（秘匿の影響を受けない）
- **都道府県別・年齢群別・性別 → 内訳セル**（総計列は分割できないため）

と使い分けている。後者にだけ識別区間の評価が必要になるのは、この構造による。

なお総計列自体が秘匿されている品目行も全期間で181件存在する（いずれも1,000未満）ため、
公表総計も厳密には下限値だが、影響は全期間合計で181,000 mL（全体の0.09%以下）に限られる。

## 8. 再検証の方法

本ドキュメントの数値は以下で再現できる。

```bash
python allergy解析/verify_methods_claims.py
```

ただし同スクリプトは元原稿（公費含む版）の数値をハードコードして照合するため、
公費含まない版と比較すると差分が「NG」と表示される。これは想定される挙動である。
