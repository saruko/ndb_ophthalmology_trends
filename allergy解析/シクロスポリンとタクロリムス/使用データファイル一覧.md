## 1. 公費レセプトの取り扱い（重要）

**全11年度を通じて「公費レセプトを含まない」集計表を使用している。**

- 第1回〜第10回（2014〜2023年度）は公費レセプトを含まない集計表**のみ**が公表されているため、通常の `data/raw/ndb_gaiyo_*.xlsx` がそのまま該当する。
- 第11回（2024年度）は公費レセプトを**含む**集計表が標準となったため、同時公表された「含まない」版（`data/raw/ndb_2024_nokouhi/`）を明示的に使用している。

スクリプト内の該当箇所（`build_immunosuppressant_analysis.py`）:

```python
def pref_file(year):
    if year == 2024:
        return os.path.join(NOKOUHI, "ndb_gaiyo_2024_nokouhi.xlsx")
    return os.path.join(RAW, f"ndb_gaiyo_{year}.xlsx")

def agesex_file(year):
    if year == 2024:
        return os.path.join(NOKOUHI, "ndb_gaiyo_agesex_2024_nokouhi.xlsx")
    return os.path.join(RAW, "ndb_age_sex", f"ndb_gaiyo_agesex_{year}.xlsx")
```

### 検証: 2024年度が「公費含まない」であることの確認

本サブ解析の出力値（`national_trends_immuno.csv`）が、公費を含む集計とは異なり、親解析の公費含まない版と一致することを確認した。

| 2024年度 全国総計 | 公費**含む**（`ndb_gaiyo_2024.xlsx`） | 公費**含まない**（本解析の値） | 差 |
|---|---:|---:|---:|
| シクロスポリン（個） | 613,372 | **601,967** | −1.86% |
| タクロリムス（瓶） | 172,082.62 | **168,015.62** | −2.36% |

本解析の値は、親解析の
`allergy解析/論文に使うファイルたち/公費含まない/national_totals_published.csv`
に記録された2024年度の値（CYCLOSPORINE 601,967 ／ TACROLIMUS 168,015.62）と**完全に一致**する。

## 3. 抽出条件

各Excelの全シート（外用薬 外来(院内) ／ 外用薬 外来(院外) ／ 外用薬 入院）を走査し、以下を満たす行を抽出した。

1. 薬効分類コード（列0、`ffill` 補完後）が `131`（眼科用剤）
2. 医薬品名（列3）に `点眼` を含む
3. 医薬品名が対象2成分のパターンに一致

| コード | パターン | 全期間で該当した品目 | NDB単位 |
|---|---|---|---|
| `CYCLOSPORINE` | `シクロスポリン` \| `パピロック` | パピロックミニ点眼液0.1% 0.4mL | 個 |
| `TACROLIMUS` | `タクロリムス` \| `タリムス` | タリムス点眼液0.1% 5mL | 瓶 |

条件2により、タクロリムス軟膏（皮膚科用外用剤）は除外される。
薬剤定義は親解析 `allergy解析/src/preprocess_allergy.py` の `DRUG_CATEGORIES` と同一である。

### 値の取り扱い

- 全国集計 → 各行の公表「**総計（処方数量）**」列（秘匿されない）を3シート分合算
- 都道府県別 → 都道府県列（01〜47）の内訳セル、秘匿（`-`）は **0補完**
- 年齢性別別 → 男女×5歳階級の内訳セル、秘匿（`-`）は **0補完**
- 感度分析 → 上記の内訳セルを **999補完**（秘匿の真値区間 [0, 1000) の上限）で再計算

列位置はヘッダー行から動的に検出しているため、年度による列構成の差異（2014・2015年度は「単位」列がない等）に依存しない。単位はスクリプト内の `DRUGS[...]["ml_per_unit"]` に定数として持たせているため、「単位」列のない年度でも正しく換算される（両成分とも全期間で品目が1つずつのみで、単位の変更もないことを確認済み）。

## 5. 親解析との関係

| 項目 | 親解析 | 本サブ解析 |
|---|---|---|
| 手法の準拠元 | — | `論文に使うファイルたち/公費含まない/allergy_paper_draft_kouhihukumanai.md` |
| 対象成分 | 11成分（抗ヒスタミン4・遊離抑制5・免疫抑制2） | 免疫抑制2成分のみ |
| 公費レセプト | 全年度「含まない」 | 同一 |
| 秘匿補完 | zero（感度分析でupper） | 同一 |
| 全国集計の基準 | 公表「総計」列 | 同一 |
| 人口分母 | 総務省人口推計 | 同一 |
| **処方数量の単位** | **全成分を一律「mL」として合算** | **「個」「瓶」とmL換算値を分けて集計**（下記参照） |

単位の扱いのみ親解析と異なる。詳細は `allergy解析/処方数量の単位に関する検証.md` を参照。
