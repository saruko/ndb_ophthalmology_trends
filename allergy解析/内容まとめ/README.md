## 主要な解析結果サマリー

### 処方量トレンド
- 全体処方量: 109百万mL（2014）→ 213百万mL（2024）、+95.6%
- エピナスチンが市場シェア1位に浮上（13.3%→56.7%）
- オロパタジンは横ばい（64.9%→31.9%にシェア低下）

### 都道府県格差
- 最大/最小比 = 3.05倍（東京218.6 vs 沖縄71.6、人口10万対千mL）

### GE普及
- オロパタジン: 2021年GE初出 → 2024年に83.2%到達（普及速度 k=2.90）
- エピナスチン: 2021年GE初出 → 2024年に54.4%（k=0.58）
- レボカバスチン: 2015年GE初出 → 2024年に75.0%（k=0.17）

### 年齢分布
- 平均処方年齢: オロパタジン +7.2歳（47.3→54.5）、エピナスチン +2.1歳、レボカバスチン +4.8歳
- GEシェアと処方年齢の相関: オロパタジン ρ=+0.853 (p=0.001)

### データの注意事項
- 2016・2017年度: NDB第3・4回のセルレベル秘匿によりエピナスチン処方量が過少推計
- 2021年度: NDB集計方法の移行期で一部データに不連続あり
- 処方量は mL ベース（処方数量）であり、処方箋枚数や患者数ではない

## NDBオープンデータの年度間非互換性（単純比較できない点）

NDBオープンデータは年度（リリース回）によって公表仕様が異なり、全期間を単純比較できない箇所がある。本解析で確認した5つの差異を以下に記載する。

### 1. セルレベル秘匿の厳格化（2016・2017年度）— 最も深刻

NDBオープンデータ第3回・第4回（2016・2017年度）では、処方数量が1,000未満のセルが「‐」で秘匿される。さらに「1,000未満の箇所が1箇所の場合は総計以外全て‐で表示」というルールが適用された。

**影響:**
- エピナスチンの外来（院外）シートで年齢・性別の全セルが秘匿。総計値は公表されているが内訳が取れない
- 都道府県別データでも小処方量セルが秘匿されており、マイナー薬剤は多くの県で欠損

**データ捕捉率（2016・2017年度の年齢別データ）:**

| 薬剤 | 捕捉率 | 主な欠損 |
|---|---|---|
| エピナスチン | 約18% | 外来（院外）が全セル秘匿 |
| レボカバスチン | 約55% | 外来（院外）の一部年齢セルが秘匿 |
| オロパタジン | 約81% | 処方量が多く秘匿の影響は限定的 |

**対処:** 2016・2017年度の処方量は大幅な過少推計であり、他年度と単純比較できない。トレンド解析では†マークを付し、感度分析として2016-2017を除外した検証を併記する。

### 2. Excel列構成の変化（3パターン）

| 年度 | 総計列位置 | 変更点 |
|---|---|---|
| 2014 | col 7 | 単位列なし |
| 2015〜2021 | col 8 | 単位列が追加されcol 8に移動 |
| 2022〜2024 | col 8 | ヘッダー表記が「総計」→「総計\n(処方数量)」に変更 |

**対処:** スクリプトではヘッダー行を動的検索（`find_total_col()`）して吸収。列番号のハードコードは不可。また2016年以降のタイトル行（row 0）の注記テキスト中に「総計」の文字が含まれるため、検索範囲をrow 2〜4に限定する必要がある（row 0-1を検索するとタイトル行の「総計」を誤検出する）。

### 3. 年齢区分の変更（2014-2015 vs 2016以降）

| 年度 | 区分数 | 最上位区分 |
|---|---|---|
| 2014-2015 | 19区分 | 「90歳以上」（90+）の1区分 |
| 2016以降 | 21区分 | 「90-94歳」「95-99歳」「100歳以上」に細分化 |

**対処:** 90歳以上の年齢別詳細解析は2016年以降に限定する。全期間で比較する場合は90歳以上を「90+」に再統合する必要がある。スクリプト `preprocess_age_sex_allergy.py` で自動対応済み。

### 4. タイトル行の注記テキスト追加（2016以降）

2015年以前:
```
診療年月：H27年04月～H28年03月　外用薬 外来（院内）
```

2016年以降:
```
診療年月：H28年04月～H29年03月　外用薬 外来（院内）　※集計結果が1000未満の場合は「‐」で表示
（1000未満の箇所が1箇所の場合は総計以外全て「‐」で表示）
```

**対処:** タイトル行の注記中に「総計」の文字が含まれるため、総計列の動的検索（上記2.参照）ではrow 0-1を除外する必要がある。

### 5. 2021年度の不連続

NDB第8回（2021年度）で一部データに不連続が見られる。

- レボカバスチンGEシェアが56.0%（2020）→44.6%（2021）に一時低下
- 全体処方量が前年比で不自然な減少（COVID-19受診控えの影響も重畳）

集計方法の移行期の影響が疑われるが、厚労省から公式な説明はない。

**対処:** 2021年度を含むトレンド解析では不連続の可能性を注記する。

### 論文での推奨される記載

上記の非互換性を踏まえ、論文では以下の対処を推奨する。

1. **2016・2017年度のデータには†マークを付し、脚注で秘匿の影響を明記**
2. **主要なトレンド解析は2018〜2024年の7年間で実施し、2016-2017を含めた全期間解析は感度分析として併記**
3. **90歳以上の年齢別詳細解析は2016年以降に限定し、その旨を記載**
4. **Limitations セクションに以下を記載:**

> NDBオープンデータの第3・4回リリース（2016・2017年度）では、セルレベル秘匿基準の厳格化により、エピナスチン外来（院外）処方の年齢・性別内訳が全セル秘匿されている。このため、当該年度の年齢別分布推定は外来（院内）および入院分のみに基づく不完全な推計であり、処方量の経年比較においては過少推計となっている。また、2014-2015年度は年齢区分が19区分（最上位「90歳以上」）であり、2016年度以降の21区分と直接比較する場合は再統合が必要である。
