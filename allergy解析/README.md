# NDB 抗アレルギー点眼薬 トレンド・地域格差解析
**Sub-analysis of Anti-allergic Eye Drops using NDB Open Data (2014-2024)**

本サブプロジェクトは、「NDBオープンデータ（第1回〜第11回：2014年度〜2024年度）」の外用薬データから、
**眼科の抗アレルギー点眼薬**の全国処方トレンド、地域格差、眼科医療資源との関連を定量化するパイプラインです。
補助的に、注射薬（DUPIXENT/ZOLEAIR）のパネル回帰分析も実施します。

---

## 研究背景と学術的価値

### 旧アプローチ（注射薬）の問題点
- 抗IgE抗体（ゾレア）、デュピクセント、アレルゲン免疫療法薬は眼科以外（耳鼻科・皮膚科・呼吸器科）での処方が大多数
- 処方科の情報がないため、眼科医療資源との関連付けが理論的に成立しない
- 回帰分析の Within R² が全て負値（モデルが当てはまらない）

### 新アプローチ（点眼薬）の利点
- 抗アレルギー点眼薬はほぼ100% 眼科で処方される
- 眼科医師数・眼科施設数を共変量として使用することに学術的根拠がある
- 抗ヒスタミン点眼薬（新世代）への処方シフトを11年間で可視化
- 春季カタル等の重症アレルギー性結膜疾患の治療アクセス格差を検出可能

### 2.3 秘匿閾値と感度分析（識別区間）

**外用薬（処方薬）の秘匿閾値は「処方数量1,000未満」であり、全年度・全シート共通である。**
生データ検証により、非秘匿セルの最小値は2015年度1,004.65／2016年度1,005／2017年度1,000／
2024年度1,000であり、**1,000未満の実測値は全年度で1件も存在しない**ことを確認した。

> **⚠️ 過去の記載誤りに注意**
> 「集計値10未満（2016・2017年度のみ1,000未満）が秘匿」という記載が過去のドキュメントに
> あったが誤りである。閾値は全年度1,000。このため `--imputation five`（5充当）および
> `random`（1〜9の乱数）は閾値10を前提とした旧仕様であり、本データでは実質的に
> `zero` と同義で感度分析の役に立たない。

秘匿セルの真値は区間 [0, 1000) にあるため、0充当（下限）と999充当（上限）で全指標を
再計算し、公表値のみから到達可能な識別区間を求める。

```bash
python allergy解析/run_censoring_sensitivity.py
```

出力: `03_解析結果/品質管理_感度分析/censoring_sensitivity_allergy.csv`（年度×薬剤の区間）、
`03_解析結果/品質管理_感度分析/censoring_sensitivity_disparity.csv`（格差指標）、
`03_解析結果/品質管理_感度分析/censoring_sensitivity_report.txt`（レポート）

| 点眼薬全体 | 172,204 | 176,182 | +2.3% |
| 抗ヒスタミン合計 | 167,641 | 169,987 | +1.4% |
| エピナスチン | 97,648 | 98,182 | **+0.5%** |

**主要3成分の不確実性は +0.5〜3.1% と小さく、論文の主要な結論は秘匿の影響を受けない。**
一方、処方量の小さいメディエーター遊離抑制薬・免疫抑制薬は区間幅が大きく、絶対量の解釈には

### 2.4 バグ修正と精査履歴（2026年6月）

2026年6月のコード精査により、前処理辞書（`DRUG_CATEGORIES`）のバグ修正およびNDBデータの構造検証を実施しました。

#### 1. 先発アレルギー点眼薬「インタール」のマッチング漏れ修正
- **問題点**: `src/preprocess_allergy.py` において、`CROMOGLICATE`（クロモグリク酸）の分類キーワードに `"クロモグリク酸"` しか指定されていなかったため、先発品名である `"インタール"` を含む行（例: `インタール点眼液ＵＤ２％` 等）が抽出から漏れていました。これにより、カバレッジ制限のあった2015〜2021年度のデータが 0件と誤判定され、2022年以降のフルカバレッジデータでも過小評価されていました。
- **対策**: キーワードリストに `"インタール"` を追加。
- **効果**: 2015年度などの過去データから 180万件以上の処方が正しく抽出され、`CROMOGLICATE` カテゴリが2015年以降（2015, 2017, 2018, 2022, 2023）で3点以上の有効なデータ点を持つようになり、経時的な年平均変化率（APC）の計算も正常に行えるようになりました。

#### 2. 2021年以前に一部の薬剤データが欠損する理由の検証
- ケトチフェン、ペミロラスト、イブジラスト、タクロリムスなどの点眼薬が2021年以前に完全に0件となるのは、プログラムの抽出バグではなく **NDBオープンデータそのものの収録仕様による制限**（2021年以前は上位品目のみの制限公表だったため、下位・ニッチ薬剤がExcelシートから除外されていたため）であることを、生データセルの全検索によって実証しました。

#### 3. 都道府県列マッピングの正確性検証
- NDBオープンデータのExcelファイルは、2014-2015年度は「総計列が8列目（`TotalCol=7`）」、2016-2024年度は「総計列が9列目（`TotalCol=8`）」と列構造が変化しています。
- 解析コードの動的列抽出機能（`TotalCol` からの都道府県名の自動検索）が正常に動作し、全11年分のシートにおいて **47都道府県が1列のズレもなく完璧にマッピングできている** ことを確認・実証しました。

#### 4. パネル回帰結果の上書きバグ修正（2026年7月）
- **問題点**: ステップ2（点眼薬）とステップ5（注射薬）の両方が `run_panel_regression()` を呼び出し、同じファイル名 `panel_regression_summary_allergy.csv` に出力していたため、注射薬の結果が点眼薬の結果を上書きしていました。
- **対策**: `run_panel_regression()` に `summary_filename` パラメータを追加し、注射薬は `panel_regression_summary_injection_allergy.csv` に出力するよう変更。

### 2.5 2016・2017年度のセルレベル秘匿による処方量過少推計

**NDB第3・4回リリース（H28=2016年度、H29=2017年度）において、エピナスチン（アレジオン点眼液）の外来（院外）シートで、年齢・性別別の全セルが秘匿（"-"）となっており、当該年度の処方量が著しく過少推計されています。**

#### 確認された事実

| 年度 | 外来院外 集計総量（NDB記載） | 年齢・性別セル（42個） | `ndb_allergy_age_sex_zero.csv` 上の取込量 |
|---|---|---|---|
| 2015 | 23,295,630 | 全セル数値あり（秘匿=0件） | 正常 |
| **2016** | **29,507,567** | **全42セル "-"（秘匿）** | **≈0（大幅過少）** |
| **2017** | **40,162,750** | **全42セル "-"（秘匿）** | **≈0（大幅過少）** |
| 2018 | 50,326,322 | 2セルのみ秘匿 | 正常 |

#### メカニズム

- `preprocess_age_sex_allergy.py` は年齢区分列から値を取得し、秘匿値 "-" を 0（ゼロ補完時）で補完する
- 2016・2017年の外来院外シートでは、NDB公表時点で年齢・性別内訳が全セル秘匿済みのため、パーサーは当該年度の外来院外分をすべて 0 として集計する
- 集計総量（`総計` 列）は正常値が記載されているが、パーサーはその列を使用しない

#### 解析への影響

#### 年齢・性別データの捕捉率（実測、秘匿されない総計列を分母）

| 年度 | エピナスチン | レボカバスチン | オロパタジン |
|---|---|---|---|
| 2014 | 100.0% | 100.0% | 100.0% |
| 2015 | 100.0% | 99.9% | 100.0% |
| **2016** | **18.4%** | **54.0%** | **80.6%** |
| **2017** | **17.5%** | **57.4%** | **81.1%** |
| 2018 | 100.0% | 99.9% | 100.0% |
| 2019 | 100.0% | 99.9% | 100.0% |

エピナスチン外来（院外）の年齢・性別ブロックは2016・2017年度とも**42セル中42セル（100%）が秘匿**。
同一薬剤の外来院内シートの秘匿率は4.8%に過ぎず、これは数量1,000未満の通常の少数セル秘匿ではなく、
**ブロック単位の一括非公表**である（各セルの想定値は数十万〜200万mLで閾値を大きく上回る）。

| 指標 | 影響 |
|---|---|
| EPINASTINE 総処方量（2016・2017） | 実態の17.5〜18.4%のみ取込（外来院外=最大シェアが消失） |
| ALLERGY_EYE_TOTAL（2016・2017） | 実態より30〜40%以上過少推計 |
| EPINASTINE 加重平均年齢（2016・2017） | 外来院内・入院分のみから推定のため信頼性低 |
| OLOPATADINE・LEVOCASTINE（同年度） | 軽微（院外の一部セルに秘匿あり、全セルではない） |

#### 対処方針

- `ndb_allergy_age_sex_zero.csv` を用いたトレンド分析（加重平均年齢・年齢分布シェア等）では、**2016・2017年は外来院外のエピナスチン分が欠損した不完全データ**として扱う
- 年次トレンドグラフでは、2016・2017年を「データ制限年度」として注釈を付すことを推奨する
- 論文 Limitations に下記を明記すること：
  > NDBオープンデータの第3・4回リリース（2016・2017年度）では、エピナスチン外来（院外）処方の年齢・性別内訳が全セル秘匿されており、これらの年度の年齢別分布推定は外来（院内）および入院分のみに基づく不完全な推計である。

### 3.1 主解析は「公費レセプトを含まない」版

第1回〜第10回（2014〜2023年度）は**公費レセプトを含まない集計のみ**が公表されている。
2024年度だけ「含む」版を使うと時系列に定義の不連続が生じるため、**経年トレンドの評価には
公費含まない版を用いる**。詳細は
[05_論文成果物/公費含まない/README.md](05_論文成果物/公費含まない/README.md) を参照。

全スクリプトが `--nokouhi`（既定）/ `--kouhi` を受け付ける。`--nokouhi` のときは

## 5. 主な解析結果（2024年度時点）

### 5.1 処方構成
- **抗アレルギー点眼薬全体**：2.13億件（人口10万対 172,204件）
  - 抗ヒスタミン薬：**97.4%** → 第一選択薬として定着

  - 免疫抑制薬：**0.4%** → 重症例のみ

### 5.2 11年間のトレンド（APC）

| 薬剤カテゴリ | APC（%) | p値 | 評価 |
|---|---|---|---|
| エピナスチン | **+20.54** | <0.001 | **最も急速に成長** |
| 抗ヒスタミン全体 | **+6.45** | <0.001 | 着実な増加 |
| 点眼薬全体 | **+6.43** | <0.001 | 着実な増加 |
| クロモグリク酸 | **−6.15** | <0.001 | 有意な減少 |
| レボカバスチン | −2.99 | 0.050 | 減少傾向（境界有意） |
| オロパタジン | −0.43 | 0.622 | ほぼ横這い |

**解釈：** 新世代抗ヒスタミン薬（特にエピナスチン）への置き換わりが進行中。旧世代薬剤は減少/停滞。

### 5.3 地域格差（2024年度）

#### 抗ヒスタミン薬 — 格差は小さい
- 変動係数（CV）：0.210
- ジニ係数：0.116
- 最大/最小比：**3.093倍**
- **解釈：** 全国どこでも同等の処方環境

#### 免疫抑制薬（パピロック・タリムス） — 格差は大きい
- 変動係数（CV）：0.488
- ジニ係数：0.275
- **解釈：** 重症患者治療へのアクセス格差が顕著

### 5.4 パネル回帰分析（Two-way FE）

眼科医師密度・眼科施設密度・高齢化率を共変量とした固定効果パネル回帰：

**抗ヒスタミン薬全体：**
- 高齢化率：係数 −293,871（p=0.020）→ **高齢化地域ほど処方が少ない**
- 眼科医密度：係数 −910（p=0.707）→ 有意な関連なし
- 眼科施設密度：係数 +2,206（p=0.583）→ 有意な関連なし
- Within R²：−0.310（モデルの説明力が低い）

**免疫抑制薬全体：**
- 眼科施設密度：係数 −262（p=0.094）→ **施設が多いほど処方が少ない傾向**
- Within R²：+0.038

**注射薬（参考）：**
- DUPIXENT: 高齢化率 係数 −31,270（p<0.001）
- ZOLEAIR: 高齢化率 係数 −1,346（p=0.009）

## 7. 推奨される論文構成

### 背景
眼科アレルギーの薬物療法は第2世代抗ヒスタミン点眼薬へ急速にシフト中。全国規模の処方実態・地域格差の最新知見に欠ける。

### 方法
- データソース：NDBオープンデータ外用薬（2014〜2024年度、11年間）
- 統計手法：APC（Joinpoint regression）、Gini係数、Two-way FEパネル回帰
- 共変量：眼科医師密度、眼科施設密度、高齢化率（都道府県別）

### 結果
1. **処方構成の推移**：エピナスチン APC +20.54% で第一選択薬に
2. **地域格差**：抗ヒスタミン薬は均等（3.093倍）、免疫抑制薬は大（Gini 0.275）
3. **共変量との関連**：高齢化率と処方量に負の関連（p=0.020）

### 考察
- 新世代抗ヒスタミン薬の圧倒的優位の確立
- 重症アレルギー性結膜疾患治療へのアクセス格差が存在
- 専門性の高い治療の集約化の可能性

### Limitations
- 処方科の情報なし（点眼薬のため信頼性高い）
- 2022年以降のNDBカバレッジ拡大の影響
- 処方理由・患者背景の情報なし
- 花粉飛散量（スギ・ヒノキ）は地域別処方の重要な交絡因子となりうるが、47都道府県を11年間にわたり同一測定法で網羅する系統的データが存在しないため共変量に含めることができなかった。年度固定効果が全国的な花粉飛散量の年次変動を制御していると考えられる。

## 8. 年齢別処方量解析（追加解析）

**入力:** `data/raw/ndb_age_sex/ndb_gaiyo_agesex_*.xlsx`（NDB外用薬・年齢性別別ファイル）  
**データ:** `02_中間データ/ndb_allergy_age_sex_zero.csv`（5,094行）  
**詳細レポート:** `age_sex_analysis_results.md`

> **⚠️ 生成スクリプトが現存しません**
> この CSV を生成した `preprocess_age_sex_allergy.py` はリポジトリ内に存在しません（過去に削除
> されたと思われる）。CSV は生成済みのものが残っており、下流の `analysis_age_sex_rates.py` と
> `generate_paper_csvs.py` はこれを読み込んで動作します。生データからの再生成が必要になった
> 場合はパーサーの再実装が必要です。

### 解析の目的

NDB外用薬の「年齢・性別別データ」を用い、アレルギー性結膜疾患治療薬の**年齢階層別処方量**を把握し、疾患の年齢分布を間接的に推定する。

### 主な解析結果

**Q: アレルギー性結膜疾患の処方は若年化しているか？**  
→ **若年化は認められない。緩やかな高齢化傾向を示す。**

#### ⚠️ 2つの集計範囲の使い分け

本解析には意味の異なる2つの集計単位がある。**どちらを使ったかを必ず明示すること。**

| コード | 内容 | 年度間比較 | 用途 |
|---|---|---|---|
| `ALLERGY_EYE_TOTAL` | 抗アレルギー点眼薬**全体**（その年度にNDBが収録した全成分の合計） | **不可** | 単年断面の記述（構成比・年齢分布・男女比） |
| `TOP3_TOTAL` | エピナスチン＋オロパタジン＋レボカバスチンの**主要3成分合計** | **可** | 経年トレンド・都道府県比較 |

全体合計が年度間比較に使えないのは、NDBオープンデータの公表仕様変更により**収録成分数が年度ごとに
変動する**ためである。

| 年度 | 収録成分数 | 3成分が全体に占める割合 |
|---|---|---|
| 2014 | 3成分 | 100.0% |
| 2015 | 7成分 | 94.7% |
| 2016 | 6成分 | 96.6% |
| 2017 | 7成分 | 97.2% |
| 2018 | 5成分 | 98.3% |
| 2019–2021 | 3成分 | 100.0% |
| 2022–2024 | 11成分 | 95.8 / 96.1 / 96.7% |

2014年および2019–2021年の「全体」は**実質的に主要3成分そのもの**であり、11成分を含む2022年度以降と
直接比較すると、成分の追加による見かけ上の増加を実態の増加と誤認する。

#### 加重平均年齢の推移（2014→2024年）

**主要3成分合計（経年比較にはこちらを使用）**

| 薬剤カテゴリ | 2014年 | 2024年 | 変化 |
|---|---|---|---|
| 主要3成分合計（`TOP3_TOTAL`） | 48.3歳 | 49.5歳 | **+1.2歳** |
| オロパタジン | 47.3歳 | 54.5歳 | **+7.2歳**（顕著な高齢化） |
| レボカバスチン | 54.5歳 | 59.3歳 | +4.8歳 |
| エピナスチン | 43.2歳 | 45.3歳 | +2.0歳（ほぼ横ばい） |

**点眼薬全体（`ALLERGY_EYE_TOTAL`、参考値）**

| 薬剤カテゴリ | 2014年 | 2024年 | 変化 |
|---|---|---|---|
| 点眼薬全体 | 48.3歳 | 49.7歳 | +1.4歳 |

2014年の全体は3成分のみのため3成分合計と一致する。2024年の差（49.7 vs 49.5歳）は、2022年度から
収録された8成分（ケトチフェン・ペミロラスト等、いずれも比較的高齢層に多い）が加わったことによる。
**この+1.4歳には成分追加の効果が混入しているため、処方年齢の変化として解釈してはならない。**

※変化量は丸め前の値から算出しているため、表示値どうしの差と一致しない場合がある

#### 年齢分布の構造的特徴

- **二峰性**（5〜14歳の学童ピーク＋75〜84歳の高齢者ピーク）が2014〜2024年を通じて一貫して維持

3. **レボカバスチン：最も早期のGE参入** — 2015年にGE初出（31.2%）→ 2024年で75.0%。リボスチン点眼液は最も早くジェネリック競合にさらされた。
4. **2021年の不連続** — レボカバスチンGEシェアが2020年56.0%→2021年44.6%に一時低下。2021年はNDB第8回で集計方法が移行期であった可能性、または秘匿の影響がある。

### 9.4 年齢分布との統合的解釈（セクション8との関連）

セクション8で確認されたオロパタジンの顕著な処方年齢高齢化（+7.2歳、2014→2024年）は、本セクションのGEシェア急騰と時期的に一致する。2021年以降のGE大量参入に伴い、**若年患者がより安価なエピナスチン後発品やオロパタジン後発品へ移行**し、先発パタノールの処方が高齢患者に偏った結果、平均処方年齢が押し上げられた可能性がある（市場分化仮説）。

### 9.5 データ上の注意

- **処方量は mL ベース**（処方数量）であり、処方箋枚数や患者数ではない
- **2014年度**はNDB第1回で一部都道府県の集計対象期間が限定的であった可能性がある
- **2016・2017年度**はセルレベル秘匿（[セクション 2.5](#25-20162017年度のセルレベル秘匿による処方量過少推計)）により、エピナスチンの処方量が大幅に過少推計されているが、先発品/後発品とも同様に秘匿されるため**GEシェア比率への影響は限定的**
- **2021年度**はNDB集計方法の移行期であり、レボカバスチンのGEシェア一時低下はこの影響の可能性がある

## 10. GEシェア統計解析

**スクリプト:** `src/analyze_ge_statistics.py`
**出力:**
- `03_解析結果/後発品_剤形/ge_logistic_fit.csv` — ロジスティック曲線パラメータ
- `03_解析結果/後発品_剤形/ge_age_correlation.csv` — GEシェア×平均年齢の相関係数
- `03_解析結果/後発品_剤形/ge_statistics_report.txt` — 詳細レポート

### 10.1 解析1: GE普及のロジスティック成長曲線

GEシェア（%）の時系列にロジスティック関数 `f(t) = L / (1 + exp(-k*(t - t0)))` をフィッティングし、普及動態を定量化した。

| 薬剤 | 飽和水準 L (%) | 普及速度 k | 変曲点 t0 | R² | n |
|---|---|---|---|---|---|
| オロパタジン | 79.4 (SE 4.4) | **2.900** (SE 0.83) | 2021.4 | 0.986 | 4 |
| エピナスチン | 100.0 (SE 313) | 0.580 (SE 1.01) | 2023.9 | 0.880 | 4 |
| レボカバスチン | 100.0 (SE 67) | 0.172 (SE 0.14) | 2018.9 | 0.845 | 10 |

**解釈:**
- **オロパタジンの普及速度 (k=2.90) はレボカバスチン (k=0.17) の約17倍** — パタノール点眼液のGE転換は歴史的に見て極めて急速である
- エピナスチンの推定飽和水準 L のSEが極めて大きく（313%）、GE出現からまだ4年で推定が不安定。今後のデータ蓄積が必要
- レボカバスチンはn=10と最もデータが豊富で推定は安定（R²=0.845）。飽和水準100%に向かって漸近的に普及が進行

### 10.2 解析2: GEシェアと平均処方年齢の相関（市場分化仮説の検証）

セクション9.4の「GE普及 → 先発品の処方が高齢患者に偏る」という市場分化仮説を統計的に検証した。

| 薬剤 | n | Pearson r | p値 | Spearman ρ | p値 | 判定 |
|---|---|---|---|---|---|---|
| オロパタジン | 11 | +0.755 | 0.007 ** | +0.853 | 0.001 *** | **有意** |
| レボカバスチン | 11 | +0.613 | 0.045 * | +0.636 | 0.035 * | **有意** |
| エピナスチン | 11 | +0.474 | 0.141 | +0.453 | 0.162 | 非有意 |

**解釈:**
- **オロパタジン：GEシェアと平均処方年齢に強い正の相関** (Spearman ρ=+0.853, p<0.001)。GE普及が進むほど処方年齢が上昇しており、市場分化仮説と整合する
- **レボカバスチン：中程度の正の相関** (Spearman ρ=+0.636, p=0.035)。統計的に有意だが、人口高齢化との交絡を完全には排除できない
- **エピナスチン：有意な相関なし** (p=0.162)。GE普及が2021年以降でまだ途上であること、全体の年齢変動幅が小さいこと（42.6〜45.3歳）が要因

### 10.3 感度分析: GE出現後の期間に限定

GE=0%の期間（相関を人為的に押し上げうる）を除外し、GE出現後のみで再検証した。

| 薬剤 | 期間 | n | Spearman ρ | p値 |
|---|---|---|---|---|
| レボカバスチン | 2015-2024 | 10 | +0.648 | 0.042 * |
| オロパタジン | 2021-2024 | 4 | +0.800 | 0.200 |
| エピナスチン | 2021-2024 | 4 | +0.400 | 0.600 |

- レボカバスチンはGE=0%年（2014年のみ）を除外してもρ=+0.648 (p=0.042) で**有意な相関が維持**された
- オロパタジン・エピナスチンはn=4で検出力不足。今後のデータ蓄積が必要

### 10.4 総合考察と限界

**市場分化仮説の支持度：**
- オロパタジンで最も強い証拠（全期間 ρ=+0.853***）。レボカバスチンでも感度分析込みで支持（ρ=+0.648*）
- ただし ecological data（集計データ）の時系列相関であり、**個人レベルの処方切替行動は直接観察できない**
- **疑似相関の可能性**：日本の人口高齢化とGE推進政策が同時に進行しており、GEシェアと平均処方年齢の共上昇が因果関係ではなく共通トレンドに過ぎない可能性を排除できない

**論文での記載案：**
> GEシェアと平均処方年齢の間にオロパタジン（Spearman ρ=+0.85, p<0.001）およびレボカバスチン（ρ=+0.65, p=0.042）で有意な正の相関を認めた。しかし本知見は集計データの生態学的相関であり、個人レベルの処方切替行動を直接反映するものではない。人口高齢化の交絡も完全には排除できず、因果推論には個票データを用いた分析が必要である。

### 12.3 アレジオン眼瞼クリームの除外

2024年度のNDBオープンデータにはエピナスチン塩酸塩眼瞼クリーム（アレジオン眼瞼クリーム0.5%、2024年6月上市）が収録されている。本解析パイプラインでは薬効分類131（眼科用剤）かつ医薬品名に「**点眼**」を含む行のみを抽出対象としているため（`preprocess_allergy.py:19`）、眼瞼クリーム製剤は自動的に除外されている。今後同剤が普及した場合は、別途解析を追加する必要がある。

## 15. 数値の丸め規則と論文用CSVの構成

### 15.1 統一丸め規則

解析スクリプト全体で以下の桁数に統一している。

| 対象 | 桁数 | 例 |
|---|---|---|
| 処方数量・人口10万対（率） | 整数 | 172,204 |
| 割合・シェア（%） | 小数1桁 | 97.4% |
| 割合（比率 0–1） | 小数3桁 | 0.649 |
| 比（M:F・最大/最小）・CV・Gini | 小数3桁 | 0.402 / 3.087 / 0.116 |
| 回帰係数・標準誤差・t値 | 小数3桁 | −0.512 |
| APC（%） | 小数2桁 | +6.43 |
| R² | 小数4桁 | 0.8267 |
| 加重平均年齢 | 小数1桁 | 45.3 |
| p値 | 表示3桁、0.001未満は `<0.001` | — |

**p値のみ扱いが異なる。** CSVでは `p_value` に生値を保持し、表示用文字列を `p_value_display` に
別列で併記する。3桁に丸めると p=1e-8 が 0.000 となり有意性情報が失われるため。

### 15.2 論文用CSVの丸め列併記

`add_rounded_columns.py` により、各数値列 X の直後に `X_rounded` を挿入している。
実データ（X）はそのまま保持されるため、論文表記値と生値の両方を1ファイルで確認できる。

```text
age_group  count         count_rounded  count_per_100k  count_per_100k_rounded
5-9        1.558493e+07  15584932       330749.824278   330750
```

### 15.3 ⚠️ CSVをExcelで開く際の注意

`age_group` 列の `5-9` `10-14` は、**ExcelでCSVを開いて保存すると日付（`5月9日` `10月14日`）に
変換されて破損する**。実際に `age_sex_rates_allergy.csv` 等4ファイルで発生した。

この破損は下流で例外を出さず、`age_group == "5-9"` でのフィルタが静かに0件マッチするため、
誤った集計値が生成される。閲覧のみに留めるか、保存せずに閉じること。

`generate_paper_csvs.py` の `sort_age()` および加重平均年齢の算出前に未知ラベル検知
（`_check_age_labels`）を入れており、破損データが混入した場合はエラーで停止する。
