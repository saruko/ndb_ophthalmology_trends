# NDBとの比較（参考解析・triangulation）

薬事工業生産動態統計（外部データ）を使って、NDBオープンデータが眼科用剤市場を
どれだけ捕捉しているかを検証した。査読指摘①「足切りで非掲載の薬剤があるのに
3成分のシェアが多いと言えるのか」に対する**NDB外部からの傍証**。

生成: `../build_ndb_vs_yakuji.py`（再実行可能）
結論と方法の詳細: **[coverage_report.md](coverage_report.md)**

## 主要な結果

- **足切りで隠れていた品目は金額ベースで市場の約1割**。2021→2022年度に
  掲載品目数は162→531（3.3倍）に増えたが、薬価金額は+11.7%しか増えなかった。
- 2015〜2024年度の捕捉率は薬価ベース（k=1.0）で90〜110%。NDBは市場の大宗を捕捉している。
- **2014年度（第1回）だけは例外**で、掲載55品目・捕捉率69.5%と際立って低い。
  2014年度単独の水準・シェアを論じる際は特段の注意が必要。

## 読むときの注意

分子（NDB）は**薬価**、分母（統計）は**メーカー販売単価**で価格基準が違うため、
捕捉率の点推定はできない。仕切価率 k を振った幅として読むこと。
k=1.0 で100%を超える年度があるのはこの価格基準差によるもので、
NDBが市場を超えて捕捉しているという意味ではない。
