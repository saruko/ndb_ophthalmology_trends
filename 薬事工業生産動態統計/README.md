# 厚労省「薬事工業生産動態統計」raw data

NDBオープンデータの捕捉率検証（参考解析）用。2026-08-08 に e-Stat から取得。

- 政府統計コード: 00450151（薬事工業生産動態統計調査）
- 取得元: https://www.e-stat.go.jp/stat-search/files?toukei=00450151
  各年の「（統計表）薬事工業生産動態統計調査」＞年次 から
  `file-download?statInfId=<ID>&fileKind=<0|1>` で直接取得
- ファイル名は `<年>_<表名>_<statInfId>.<xls|csv>`（IDから取得元を一意に遡れる）

- 2014〜2018年: .xls（Excel）
- 2019〜2024年: .csv（UTF-8 BOM。e-Stat の fileKind=1）
- **2019年に調査方法が全面変更**（オンライン化・全数報告）されており、
  2018年以前と2019年以降の時系列接続には注意
- 年報の集計期間は**暦年（1〜12月）**。NDBは年度（4月〜3月）なのでズレがある

## 検証済み事項（取得時）

- 全11年で薬効分類「131 眼科用剤」の行が存在することを確認
- 金額単位は千円。例: 2024年の眼科用剤 出荷計 434,179,807千円（約4,342億円）、
  うち国内 421,658,580千円・輸出 12,521,227千円、品目数1,012
- 2014年: 出荷計 352,493,132千円（品目数936）

## 「出荷金額」の定義（厚労省FAQで確認済み）

**出荷金額 = 出荷数量 × 販売単価**。販売単価は製造販売業者（メーカー）が
連結企業体外（卸等の市場）へ販売する実勢の単価で、運賃・積込料を含み、
返品は控除、預託は出荷に含む。**薬価換算ではない**。
