# NDB 眼腫瘍手術トレンド解析

**National trends in ophthalmic tumor surgery using NDB Open Data (2014–2024)**

NDBオープンデータ（第1回〜第11回：2014年度〜2024年度）の**手術（shujutsu）**ファイルから
**眼腫瘍関連16術式**を抽出し、全国算定回数の年次推移・年齢階級別分布・
人口10万対rate換算・Poisson回帰によるtrend test（傾向性検定）を行うパイプライン。

## 3. 解析内容と出力ファイル

### 3-1. extract_age_stratified.py（年齢階級別の抽出・4群層別化）
5歳刻み19区分を4群に集約する（`bracket_to_group`）:
小児(0-14) / AYA(15-39) / 成人(40-64) / 高齢者(65+)。
秘匿値（`-`）は**0として合算**する（本体 `preprocess.py` のzero補完方針に合わせた）。

| 出力 | 内容 |
|---|---|
| `眼腫瘍手術_年齢階級別_2014_2024.csv` | 5歳刻み・男女別の生データ |
| `眼腫瘍手術_4群層別化_2014_2024.csv` | 4群集計 |
| `眼腫瘍手術_年齢別合計_整合性チェック用_2014_2024.csv` | 年齢を合計した値（**rate換算・trend testには使わない**、§4-1参照） |

### 3-2. extract_age_population.py（4群別の全国人口）
年齢を4群に集約し `人口_4群層別化_2014_2024.csv` を出力する。
4群合計の総人口が総務省公表値（2014年127,078千人、2024年123,802千人）と一致することを確認済み。

**2015年度・2020年度は線形補間**: 国勢調査実施年のため「人口推計」の年次ページ自体が存在せず
（`stat.go.jp/data/jinsui/2015np/`, `2020np/` はいずれも404）、前後年（2014/2016, 2019/2021）から
補間して代用した（`build_real_covariates.py` の医師数・施設数と同じ補間方針）。
該当年には `is_interpolated=True` のフラグが立つ。

### 3-3. rate_and_trend_analysis.py（rate換算・trend test）
| 出力 | 内容 |
|---|---|
| `rate_per_100k_national_trend.csv` | 術式別・年次別の全年齢人口10万対rate |
| `poisson_trend_test_results.csv` | 術式別のAPC・95%CI・p値・除外理由（`note`列） |

粗数トレンドとrateトレンドの方向一致は全16術式で確認済み（コンソール出力に一致判定あり）。

## 4. 解析手法と重要な設計判断

### 4-1. rate換算・trend testの分子には「真の全国合計」を使う
`extract_age_stratified.py` が出力する年齢別合計は、セル単位の秘匿により低頻度術式ほど
過小評価される。そのため rate換算・trend test には**都道府県別集計由来の全国合計**
（`眼腫瘍手術トレンド_2014_2024.csv` の `Total_Count`、`-` は0補完）を使用し、
年齢・性別クロス集計は**年齢階級別の内訳表示にのみ**使う。この使い分けが本解析の肝である。

整合性チェックの結果:
- 高頻度術式（K215-2, K225-2, K225-3, K234等）: 乖離は数%以内で妥当
- **低頻度術式（K233, K236, K245, K265, K266, K225-4）: 大半〜全部が0として欠測**
  （K265/K266は全年度でほぼ0件しか復元できない）

### 4-2. Poisson回帰の仕様
`count ~ year`（`year` は連続変数）に `offset = log(全年齢人口)` を与えたPoisson GLM
（`statsmodels.api.GLM` + `families.Poisson()`）。
- APC (Annual Percent Change) = `(exp(β_year) - 1) × 100`、95%CIも同様に `exp` 変換
- p値は `year` の係数のWald検定

### 4-3. 除外・特例ルール（`note` 列に理由を記載）
- **K265, K266**: 全年度でcountがほぼ0（秘匿による実質全欠測）のためPoisson回帰が数値的に破綻する。
  `EXCLUDED_CODES` で明示的に除外
- **K225-4**: 2022年度新設コードのため観測3年のみ。11年間のtrend testの対象外
- **K225**: 2022年度のK225-4新設による構造的断絶があるため、**改定前（2014〜2021年度）の8年間のみ**で
  trend testを実施。11年通しの単一線形回帰は断絶を均すため採用しない
- 上記以外で全年度count=0のコードがあった場合も同様にスキップするフォールバックあり

## 6. ⚠️ 2024年度のみ公費レセプトを含む（時系列の不連続）

**本解析の2024年度の値は、2023年度以前と集計定義が異なる。**

第11回（2024年度）から公費レセプトを**含む**集計が標準になった一方、第1回〜第10回
（2014〜2023年度）は**含まない**集計のみが公表されている。本解析が使う2024年度のファイルは
`款別性年齢別算定回数(公費含む).xlsx` であり（§2-2のURL表を参照）、
`眼腫瘍手術トレンド_2014_2024.csv` の2024年度分も同様に公費を含む。

同じ第11回で両版が手元にある唯一の診療行為（G016 硝子体内注射）で実測した差:

| G016算定回数 | 2023年度 | 2024年度 |
|---|---:|---:|
| 標準ファイル（公費含む） | 1,039,173 | 1,104,430 |
| 公費含まない版 | 1,039,173 | 1,067,660 |
| 差 | **0** | **+36,770（+3.44%）** |

K手術でも同程度の上振れが2024年度のみに生じていると考えられる。

**具体的な影響**
- `rate_per_100k_national_trend.csv` の2024年度の rate は約3%過大の可能性
- **`poisson_trend_test_results.csv` のAPCは全16術式で上方バイアスを受ける。**
  11年系列の最終年だけが約3%高いため、増加傾向の術式（K234 +5.92%/年、K225-2 +1.34%/年）は
  やや過大に、減少傾向の術式（K241 −5.84%/年 等）はやや過小に評価される。
  影響の大きさはおおよそ **APC で +0.3ポイント程度**（3.4%を10年で割った目安）であり、
  **有意性が境界的なもの（K245: p=0.049、K216: p=0.009）は解釈に注意**が必要
- 年齢階級別の構成比は比率なので影響は小さい

**対応方針（2026-08-02 決定）: 当面はこのまま運用し、論文の Limitations に明記する。**
処方薬については `data/raw/ndb_2024_nokouhi/` に含まない版があるが、
**手術（shujutsu）の含まない版は未入手**である。取得できれば切り替えを追加して再実行する。

Limitations にそのまま使える記載文（日本語・英語）は

## 7. つまずいた点・技術的メモ（再実行時の参考）

- **Windows環境のターミナル文字コード**: `python` 実行時のprint出力がcp932ターミナルで文字化けする
  （ファイル自体はutf-8-sigで正しく保存されるので実害はない）。`PYTHONIOENCODING=utf-8` で回避できる。
- **`.xls` 読み込みにはxlrdが必要**: `pandas.read_excel` は `.xlsx` はopenpyxl、`.xls` はxlrdを使う。
  2014・2016〜2018年度の人口推計ファイル（.xls形式）を読むには `pip install xlrd` が別途必要。
- **`statsmodels` の `conf_int()` の戻り値**: `sm.add_constant` にnumpy配列を渡すと
  `result.conf_int()` はDataFrameではなくnumpy配列を返すため、`.iloc[1]` ではなく `[1]` でアクセスする。
- **人口推計ページのURL規則が年度でバラバラ**: 元号年（`05k26-1.xls`）／令和元年（`05k01-1.xlsx`）／
  西暦（`05k2021-1.xlsx`）が混在し、国勢調査年（2015, 2020）はページ自体が存在しない。
  別の年度を追加する場合は `https://www.stat.go.jp/data/jinsui/{year}np/` の実在を確認し、
  ファイル名は都度ページから確認する（命名規則を機械的に推測しない）。
- **`is_interpolated=True` が2015・2020になる理由**: 国勢調査年は国勢調査自体が最も正確な人口データだが、
  それは総務省「人口推計」（毎年10月1日現在の推計値を年次ファイルとして公表するシリーズ）とは別物である。
  人口推計の個別年次ページは国勢調査年には作成されないため404になる。つまりこのフラグは
  「最も信頼できるデータを使わなかった」ではなく「使いたいデータソースが存在しないため補間した」の意味。
